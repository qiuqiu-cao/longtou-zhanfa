# 政策条件模型与阈值验证说明

## 开发模型

`policy_conditional_model.py` 只读取时间切分报告中的训练、校准和验证ID。盈利模型和-7%大面模型都同时训练两个候选：正则逻辑回归和带L2约束的直方图梯度提升。

基模型只拟合训练段，校准段只用于Platt概率校准，验证段按Brier分数选择最终候选，AUC仅用作同Brier时的次级规则。模型同时报告验证段样本数、基准率、AUC、Brier、Brier skill、log loss和平均预测值。

运行：

```powershell
D:/python/python.exe policy_conditional_model.py --dataset 完整交易数据集.json --split 时间切分审计.json --output 新模型目录
```

输出目录不得已经存在；内含 `policy_conditional_model.joblib` 与 `model_card.json`，并对模型文件和源文件记录SHA-256。

盲测行虽然随源JSON被解析，但不构建盲测特征矩阵、不访问盲测标签字段、不输出盲测指标。程序会明确报告源数据仍可被人员查看，因此这不是技术访问封存。

## 验证段阈值

阈值网格必须在模型训练完成前冻结，模板见 `templates/policy_threshold_config_v1.json`。替换时间和配置ID后应将文件当作不可改写证据保存。

命令：

```powershell
D:/python/python.exe policy_threshold_validation.py --model-card 新模型目录/model_card.json --config 冻结阈值.json --output 阈值验证.json
```

对每个事先给定的“最低盈利概率+最高大面概率”组合，只在验证段计算：

- 至少30笔已完成交易；
- 完整交易盈利率不低于70%；
- 完整交易大面率不高于10%；
- 平均净收益大于0；
- 在事先标记为可交易的情绪周中，平均每周3—5笔。

同时输出盈利率和大面率的Wilson 95%区间。多组通过时，固定优先保留更多交易，再比较更低大面率、更高盈利率和更严格的盈利阈值。不通过时输出 `NO_VALIDATED_THRESHOLD` 并继续空仓，不会把70%降到65%凑信号。

## 局限

模型卡始终为 `DEVELOPMENT_MODEL_ONLY`，阈值通过后 `deployment_allowed` 仍为 `false`。原因是该模型只适用于既有冻结选择策略产生的条件样本，`can_rank_unselected_full_pool=false`，且尚未进入独立盲测或新时间段前向验证。
