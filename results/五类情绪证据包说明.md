# 五类情绪证据包说明

## 两步生成

先用情绪指标长表生成因果分位参考：

```powershell
D:/python/python.exe emotion_reference_builder.py --input 情绪指标长表.csv --calendar 交易日历.csv --asof 2026-09-07T09:35:00+08:00 --output 情绪参考快照.json
```

再转换为五类情绪解释：

```powershell
D:/python/python.exe emotion_evidence_pack.py --input 情绪参考快照.json --asof 2026-09-07T09:35:00+08:00 --output 情绪证据包.json
```

日期和路径只是格式示例，不表示已有该日真实数据。

## 长表与固定分母

每行是一个交易日、一个固定市场范围、一个指标的快照，必须包含：

`date, metric, value, unit, denominator, observed_count, missing_count, scope_id, definition_id, cohort_id, source, observed_at, available_at, data_status`。

必须满足 `observed_count + missing_count = denominator`。单条损坏记录被排除并降低有效样本；结构性缺列、日历不排序/重复、当日不在日历或当日混用多个市场范围时，整批拒绝。不在交易日历的记录不进入参考。

## 因果分位

当日指标只与决策时已可用的历史记录比较，且 `scope_id`、`definition_id`、`cohort_id` 和单位完全一致。每个交易日只取最后一条快照，避免采样频率较高的日子被重复加权。默认取最近120个历史交易日，最少要60个。

输出25%、50%、75%分位、样本数、参考起止时间及最晚可用时间。这些是描述参考，不是经过反复试验挑出的盈利阈值。

## 十五个指标

- 赚钱效应：`yesterday_limit_premium`、`first_board_promotion`、`buyable_profit_rate`。
- 断板亏钱效应：`broken_tail_return`、`broken_down_limit_rate`、`contagion_scope`。
- 高中低位：`high_feedback`、`middle_feedback`、`low_feedback`。
- 题材分歧：`core_feedback`、`follower_feedback`、`withdrawal_scope`。
- 修复质量：`repair_close_retention`、`repair_volume_support`、`theme_sync`。

正向指标越高越好，负向指标如跌停率、传导范围和撤退范围越低越好。当日值落在有利方向75%分位之外标为 `SUPPORTIVE`，落在不利方向25%分位之外标为 `ADVERSE`，中间为中性。任一指标不可用时，该维度保持 `UNAVAILABLE`。

## 可解释不等于可入场

每个维度都输出盘面解释、对候选/仓位的影响和失效条件。但只有当日观察、未超时、`data_status=verified` 且固定分母覆盖率至少90%时，该维度才具备支持条件入场的资格。

`entry_support_eligible=true` 仍不是买入信号，只表示情绪证据本身完整及时。个股真实题材、竞争身份、竞价/开盘承接、价格边界、风险预算与系统上线闸门仍需另行通过。
