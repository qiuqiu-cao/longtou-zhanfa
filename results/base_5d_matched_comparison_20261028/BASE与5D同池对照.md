# BASE 与 5D 修复版同池历史对照

形成日期：2026-10-28。本次只读取保存的 BASE 历史预测与 5D 修复版四折预测，没有重训或改模型。比较结果是：这批交集样本中 5D 封板筛选略好，但优势不确定，不能确认达到替代 BASE 的资格。

为避免将两个不同范围的汇总百分比直接相减，先将 BASE 的信号日期对应至其目标交易日，再与 5D 当日预测按日期和代码取交集。范围 2025-07-02—2026-09-16，共293个日期、1,884个交集股次。两模型分别在每天相同交集成员内重新排名。原完整池与原排名不回写，交集结果不能代表两个原全池系统的完整成绩。

标签未知或冲突不剔除候选、不改变排名：6条两源标签冲突、另4条未知，合计10条标签不可统一。每日两边首选标签均已知且一致的有290天，另3天保留未知。

5D领先12次，即4.138个百分点。配对的5观察日期块bootstrap 2,000次，探索性95%区间[-2.069,+10.654]个百分点，跨越0，不能据此确认稳定提升。两者在91个已知配对日选择相同股票。完整293天分母及未知保留，不将3个未知日期视为失败或成功。

另有290个两侧次日开盘价格变化均可算的日期：BASE首选开盘至次日开盘均值-0.758%，5D为-0.108%。这一分母与封板配对按各自可用性独立确定，不能混同；只是交集内价格代理，无费用、滑点、排队及现金模拟，不能声称实际收益改善或策略可盈利。上次报告5D全495天均值-0.718%仍保留，与交集值不同是范围不同。

比较还有信息时点差异：BASE用前一日收盘信息，5D使用当日开盘信息，后者多了一段竞价信息；本次不是同一信息集合下的算法净改进检验。5D源库仍有不完整股票池、历史ST/除权及涨停基准未独立确权等限制，旧历史已被反复研究，也不是独立盲测。BASE已知的非一字漏判缺点同样保留，未因本次结论称其无缺陷。

当前选择：BASE继续作为正式盘后基础榜，5D作为竞价阶段研究参考。封板筛选历史点估计5D略好，稳定性和实际盈利尚未获证据支持；不据此替换生产模型。下一独立日期按既有规则留档，并以真实竞价截图进行终审。
