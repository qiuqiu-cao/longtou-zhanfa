# 完整交易时间切分说明

`complete_trade_split_audit.py` 将已合规的完整交易按信号日分为训练、校准、验证和盲测四段。时间边界由独立JSON事先给定，每两段之间至少留一个交易日隔离带。

对每笔交易，不只看信号日在哪一段，还检查实际平仓时间。训练信号若到校准段开始后才平仓，会从训练段清除；校准与验证段同理。盲测期末尚未平仓或越过截止日的交易也不进入盲测评价。

最低完整交易数固定为：训练100笔、校准30笔、验证30笔、盲测100笔。训练、校准和验证段的盈利标签与-7%大面标签均必须同时包含正负两类，否则不具备模型开发资格。

示例命令：

```powershell
D:/python/python.exe complete_trade_split_audit.py --dataset 完整交易数据集.json --calendar 交易日历.json --split 固定切分.json --asof 2028-12-31T16:00:00+08:00 --output 时间切分审计.json
```

盲测段只输出可用数量与决策ID，`blind_label_metrics` 保持空。但源数据集本身仍含盲测标签，所以该审计明确输出 `blind_label_access_control=NOT_ENFORCED_SOURCE_DATASET_CONTAINS_LABELS`。这只证明本程序未汇总盲测胜负，不能声称人员无法偷看。真正的独立盲测还需将标签交由独立封存文件或后续时间段管理。

该切分仍只适用于已冻结选择策略所覆盖的条件人群，不会产生未选股票的反事实成交结果。
