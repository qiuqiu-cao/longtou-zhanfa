# V6 龙头模型情绪理解力报告

数据截止：2026-08-31收盘。状态：`RESEARCH_ONLY`。本报告不构成收益保证或自动交易依据。

## 结论

这套系统已经具备“结构化识别情绪”的能力，但还不具备稳定提前预测拐点的能力。它最擅长回答当前接力生态是否健康、表面热度是否被中位亏钱效应否定；最薄弱的是在启动、升温、加速、修复这些可交易阶段中，提前区分次日继续强化还是突然转入大分歧/退潮。

可审计的能力分层如下：

| 层次 | 当前判断 | 样本外证据 |
|---|---|---|
| 当前状态识别 | 可用作环境过滤 | 669个交易日，七状态均由收盘可知字段确定 |
| 假加速/外热内弱识别 | 有明确结构规则 | 高度、宽度、中位晋级、亏钱效应、拥挤和梯队断层分开计算 |
| 次日逆风预测（全市场日） | 弱有效 | AUC 0.583；高风险20%精确率54.9%，基准发生率44.7%，提升约1.23倍 |
| 次日逆风预测（允许开仓阶段） | 不稳定 | AUC 0.533；后两段时间折AUC约0.495和0.500，未过闸门 |
| 次日接力损伤预测（全市场日） | 弱有效 | AUC 0.551；高风险20%精确率36.3%，基准发生率31.3% |
| 次日接力损伤预测（允许开仓阶段） | 暂不可用 | AUC 0.519；高风险20%精确率23.6%，低于25.9%的阶段基准 |
| 交易部署 | 不通过 | 两个目标未共同通过三段时间稳定闸门 |

## 它如何理解情绪

系统不把涨停家数直接等同于情绪强，而是拆成六条反馈链：

1. 宽度：涨停数量、增量和封板率是否扩张。
2. 接力：整体晋级、中位2—4板晋级、昨日涨停溢价和空间板反馈是否健康。
3. 梯队：高度扩张是否有中位密度支撑，是否出现板位断层和孤立空间板。
4. 亏钱效应：炸板率、跌停数、昨日涨停尾部亏损是否恶化。
5. 拥挤：一字占比、涨停宽度和高标高度是否进入一致性兑现区。
6. 脆弱度：接力弱、亏钱效应差、拥挤高、宽度与高度背离是否共振。

七阶段状态不是固定顺序。启动可以直接转大分歧，退潮也可能直接修复；因此系统同时保留状态、状态年龄、经验转移概率和监督风险概率，避免把周期理解成机械钟摆。

历史经验转移中，升温次日落入大分歧/退潮约29.9%；加速次日落入两者约43.8%；一致次日约25.0%。一致样本仅12天，证据很少，不能把该比例当稳定规律。

## 2026-08-31的具体理解

当前状态为`升温`，但属于“外热内弱、分歧预警”，不是无条件进攻：

- 涨停79家，宽度健康0.657，2—4板晋级率46.7%，梯队健康0.880，表面结构仍强。
- 空间高度从7板降至6板；跌停11家；昨日涨停平均溢价约-0.11%，尾部亏损-6.84%。
- 亏钱效应健康仅0.460，系统警告“昨日涨停股尾部亏损恶化”。
- 次日大分歧/退潮概率42.8%，显著高于当前状态的Markov基准29.8%。
- 次日接力损伤概率29.4%，与31.2%的扩展基准接近，无法形成强方向优势。

对应交易含义：环境没有关闭，但不能因79只涨停就扩大接力仓位。新增交易只能等待次日竞价、VWAP承接、真实题材同步和换手回封确认；高开无量、板块不同步、两次冲板不封或跌破VWAP放量应取消。

## 下一步优化重点

1. 剩余585只普通主板股票的历史简称/ST区间已由V7补齐；下一步转为持续归档新上市、ST变更和退市事件。
2. 增加真实题材驱动和板块同步，尤其区分医药内部细分，避免行业宽度掩盖细分退潮。
3. 将开盘确认的VWAP、首次回落量、均价收复、竞价成交占比和竞争者淘汰纳入冻结后的前向样本，而不是用日线代理。
4. 对“允许开仓阶段的逆风拐点”建立专门模型；当前全日模型的总体改善不能替代该核心子样本稳定性。
5. 继续冻结阈值并累计至少60个真实前向信号；未达到70%晋级精确率与10%大面率红线前，保持`DIAGNOSTIC_ONLY/RESEARCH_ONLY`。
