# V9 盘中情绪证据层升级报告

## 本次升级解决了什么

V8已证明日线层能较稳定地排序晋级和终局高度，但不能把T+1大面率降到10%以内。V9不再继续调整日线权重，而是新增了一个可重算、可审计的盘中证据层：

- 竞价层只导入9:20、9:24:50、9:25的原始匹配额、虚拟价、前收和前日成交额；
- 开盘层只导入1分钟OHLC、成交股数、成交额和涨停价；
- 撤单衰减、竞价成交占比、VWAP斜率、回落量比、VWAP收复、回封时间、两次冲板不封和跌破VWAP放量全部由本地代码统一推导；
- 真实题材同步仍必须绑定冻结成员名册和证据ID，行业代理不得回填；
- 原始数据必须标记为券商、终端或官方可核验导出，`inferred`、`delayed`和缺失值不能成为安全信号。

## 时点防穿越

- 竞价数据的来源时间必须位于目标快照前10秒至快照时点之间；
- 1分钟数据的来源时间不得早于该分钟结束，也不得晚于当前决策时点；
- 09:35打分会丢弃09:35之后的分钟数据，修改未来K线不会改变09:35因子；
- 同一个 `signal_date/trade_date/asof/code` 只允许导入一次，重复快照会拒绝，不会覆盖原证据。

## 影子决策逻辑

V9从V8的次日晋级、可成交代理和“至少再走两板”三个概率生成联合排序，只在允许开仓的情绪阶段中每日预注册一只3—5板观察。它可以输出：

- `DATA_LIMITED`：盘中证据缺失；
- `CANCEL`：触发高开无量、撤单衰减、题材不同步、两次冲板不封或VWAP破位等硬取消；
- `WATCH`：未形成完整换手回封链；
- `SHADOW_CONFIRM_RESEAL`：仅表示盘中链条成立，用于纸面前向验证。

无论哪个状态，V9都固定输出 `SHADOW_ONLY_NEVER_ENTER`。因为V8大面模型已被拒绝，V9将大面概率保持为缺失，不用0代替。

## 使用方式

原始导入模板：

- `data/v9/templates/auction_primitive.csv`
- `data/v9/templates/minute_primitive.csv`

生成统一口径快照：

```powershell
python intraday_evidence_v9.py --auction auction.csv --minutes minute.csv --signal-date 2026-09-01 --trade-date 2026-09-02 --asof 09:35
```

运行影子确认：

```powershell
python intraday_shadow_v9.py --signal-date 2026-09-01 --trade-date 2026-09-02 --asof 09:35
```

检查数据就绪度：

```powershell
python intraday_readiness_v9.py
```

Level-2排队、真实撤单序列和实际成交仍是 `UNAVAILABLE`，因此即使快照完整也只能作条件化纸面执行。
