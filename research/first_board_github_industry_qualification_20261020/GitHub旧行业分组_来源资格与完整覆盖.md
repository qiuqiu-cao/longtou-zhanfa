## 时间证据能证明什么

GitHub当前返回第一仓库创建于2021年3月1日、最后推送2021年3月5日、对象最后更新2021年6月6日，当前为公开、非分叉仓库。第二仓库创建于2018年10月14日、最后推送2020年7月23日。第一份数据最晚上市日期为2021年2月10日，未发现晚于旧内容范围的上市记录。

这些宿主元数据及固定树支持“当前取得的文件是旧内容”的推断。作者或提交者填写的Git日期没有被当成公开日期；GitHub官方也仅将`pushedAt`定义为仓库最后推送时间，将`updatedAt`定义为对象最后更新时间。[GitHub元数据语义](https://docs.github.com/en/graphql/reference/repos#repository)

两仓库均没有发行版本记录，且缺少独立的当年公开网页归档或原始取得收据。因此不能据当前公开状态推定精确首次公开时间，也没有填造`published_at`、原时点实际取得时间或历史行业生效日。首次公开时点和严格原时点取得资格保持未通过，原文件实际取得时间为2026年10月20日。

本批只在明确命名的“2021年固定旧类别分组”政策下用于后续历史研究，将其视为旧结构代理；不声称每只股票在信号日仍属于原行业。该政策与真实当期行业/题材资格分开记录，新源不会回写项目原行业字段或独立审阅身份卡。[机器可读资格与边界](qualified_legacy_snapshot.json)
