# 直接读旧源码后的重要补正：17项并非全是静态名称哑变量

在形成下一题材数值方案前，Codex实际读取 historical_symbolic_context.py、historical_symbolic_research.py 和 symbolic_name_theme_v217.py，发现双方前面将旧17概括为“静态名字”的说法不准确。原提案和冻结记录保留，本附页纠正，不修改当前已冻结市场情绪试验。

旧17已经包含：时点简称区间、阳洋羊扬等同音组、首板扩散/接力成员、同高度竞争、组内高度差/梯队完整度、单日首板数/份额变化、连续合格日、名称代理角色。不能再把“同音+扩散+梯队+动态变化”换名当新方案，也不能说旧模型被迫名字好就加分。其旧研究目标是已有2板以上接力池的ST_DUAL增量，并非本次完整首板28503池，但目标区别本身仍不足以自动证明新方案有效。

当前更具体、待实际Gemini反驳的增量是：父锚须从S-1或更早的活跃候选集合绑定，不能只看S同日已封板的群体；沿这组固定前一日成员追踪到S的收益、掉队和修复，包括S没涨停者。检验父锚断板与未断板时群体反馈/候选接棒的区别，以及群体尚未达到旧4成员/8%/2接力资格时是否存在可观察早期传导。不是放松旧门重跑17项，而是新增跨日成员追踪和锚条件的实际价量证据。

须先列与旧17逐字段重叠：当日成员数、首板扩散数、同位竞争/梯队、share变化仍属旧变量，不单列为新主假设；候选自身留出，所有先前组成员在当天失败和未知保留。S-1较早父锚依据用当时高度/价量规则，非论坛事后唯一父龙真值。行业/公告相关弱不否定名称叙事，但名称代理不认证市场真实题材或资金身份。合格历史名称与价量可做算法重建，不把缺独立角色金标准扩大成禁止研究。
