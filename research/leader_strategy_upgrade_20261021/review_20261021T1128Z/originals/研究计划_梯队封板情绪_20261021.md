# 龙头战法研究计划：梯队 · 封板质量 · 情绪（2026-10-21 版）

> 本计划解决的不是"下一个特征"，而是信息缺口：把用户 2026-10-21 指令点名的核心变量（梯队、封板质量、情绪）变成模型可用的、经过资格检验的信号。所有动作受 AGENTS.md 固定协议约束。

## 2. 现状基线（2026-10-21 已核实，不重跑）

- 生命周期两臂 THEME_LIFECYCLE_75 / STATUS_79：117 日验证命中 40.2% / 33.3%，**REJECTED_VALIDATION**，未部署。
- 事件路径两臂 EVENT_SEALED_PATH_67（48/117）/ EVENT_DUAL_PATH_72（46/117）：低于 BASE 52/117，**双双淘汰**；无胜者进 14 月滚动。
- 80+ 轮历史固定比较全部淘汰：E1/E2、H1/H2、R2/R3、P1、曲率、VWAP 修复、阶段响应、近期衰减、代理证据、长周期前高等。+0.5~1pp 均属噪声区间。
- 核心信息缺口：历史题材非空 = 0；真实盘口（封时/开板）三训练窗交集 0/0/17；独立角色真值 = 0；父锚时序 = 0/0/0。

## 3. 研究原则（协议固化，每批遵守）

1. **只读先行**：任何新假设先做 0 拟合条件研究 / 资格审计；有可区分证据才进入拟合。
2. **先与反重力 Gemini 讨论**新增/剔除、旧试验差别和反例，再共同冻结至多两臂。
3. 每批 = 一个假设 + 一个固定基准（原 62 字段 / BASE 52/117）+ 至多两臂 + 30 分钟预算，预算到即停。
4. 验收门不变：主口径 >52、非一字 ≥48、决策日期覆盖 ≥95%；过门才做原 14 月滚动。
5. 边界不变：不弃判弱行情、不删失败日期、不用竞价信息提高验收率、不改原预测/分数/账本/定时任务。
6. **新假设必须写明与旧失败的实际差别**，禁止换名重跑（尤其静态 17 名称因子）。
7. 自生成角色（父锚/补涨/交接）只能作训练特征或描述分层，不作独立真值；真实一字与旧低换手代理分栏。

## 4. 四条研究线

### 线 A：梯队反馈（数据已具备，第一优先开工）
- **假设**：信号日存在父锚断板/崩塌事件（parent_break_count≥1、handover_on_anchor_break=1 或 parent_collapsing_count≥1）时，当日低位首板/二板次日晋级率显著高于无断板日——"老龙死、新龙立"与断板后修复/淘汰的历史路径。
- **与旧失败的实际差别**：
  - 动态锚状态事件（跟踪锚的续板/断板/修复），**不是**静态名字相似（旧 17 名称因子已失败）；
  - 群体/梯队维度，**不是**个股自身量价形态（事件路径 67/72 刚失败）；
  - 条件描述分层，**不是**整体周期代理（阶段响应已失败）。
- **方法（0 拟合，只读）**：9245 行构建条件表——断板日/非断板日 × 首板/二板 × regime 分层，输出各格晋级率、样本数、Wilson 95% 区间、差异显著性、反例清单（断板日集体退潮日、未成功同线股）。
- **结束条件**：差异 ≥5pp 且区间不含 0 → 与 Gemini 冻结两臂（如：原 62 + 断板条件组 vs 原 62 + 扩展组）；否则淘汰并如实留档。
- **数据**：`research/model_upgrade_validation/short_term_thinking_20261015T071000Z/complete9245_causal_features_and_roles.csv` + 合法晋级标签。

### 线 B：封板质量（部分数据，先审资格再进模型）
- **假设**：信号日封板质量（一字/非一字、换手分桶、首开）携带次日承接信息；充分换手板（15~20%）承接优于一字加速板（用户"分歧转一致"）。
- **第一步（0 拟合）**：核 verified_turnover_boards / observed_nonword_boards / daily_one_word / first_open_after_one_word 的定义、非空率、与 feature_cutoff 的时点一致性；真实一字与旧低换手代理分栏。
- **第二步**：换手分桶 × 次日晋级率条件表（只读）。
- **与旧失败差别**：真实一字身份分栏（AGENTS.md 反复要求），不做 proxy 冒充；不套旧"低换手代理减分"结论。
- **结束条件**：字段资格合格且分桶有可区分差异 → 进入线 A/C 合并臂设计；否则仅留资格审计档。

### 线 C：情绪动态规则（最核心，需先与 Gemini 讨论）
- **假设**：名称/叙事 × 锚状态的动态关系（海洋王/九阳/百洋案例：高位锚→低位扩散、断板修复 vs 淘汰、羊/阳/洋跨行业叙事）携带次日晋级信息。
- **明确区别**：不是静态名字相似（旧 17 因子已失败且禁止重跑）；是"锚状态事件 × 叙事扩散"的动态条件关系；不因主营不同否决联动，也不因同音同字自动认证关系。
- **第一步**：复用 `forum_factor_design_20261021T025139Z` 三篇预读与六类候选，把情绪状态编成可编码状态机（锚续板/断板/修复 → 低位候选优先级），列出反例与取消条件。
- **第二步**：与 Gemini 讨论新增/剔除 → 冻结至多两臂（与线 A 断板条件组区分或合并）。
- **数据**：9245 中 name_cluster_members、theme_first_support、theme_relay_support、regime_* 等字段 + 限定案例回看。

### 线 D：竞价前向采集与两阶段（工程线，独立新口径）
- **目标**：从下一官方交易日 09:20 前启动竞价快照采集（复用 public_raw_capture_monitor 机制），逐日积累竞价涨幅/竞价成交额/竞价量比/未匹配委买量，并记录触发与成交证据链。
- **口径**：正式 60% 验收保持"收盘截面"（协议不变）；竞价精判作为独立新前向线，积累足够后单独评估"Top3 覆盖 + 竞价确认后的触发命中率"。
- **产出**：逐日竞价快照 + 触发/成交登记；不混正式账本，不补造历史。

## 6. 风险与边界声明

- 60% 无法靠弃判、删失败日期或用竞价回填"刷"出；本计划只通过真实信息补齐渐进提升。
