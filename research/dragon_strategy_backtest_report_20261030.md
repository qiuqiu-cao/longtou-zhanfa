## 二、 落地实现的五大维度规则

### 1. 图形结构（K线平台突破 vs 阴跌熊坑一票否决）
- 🟢 **平台突破与均线多头奖励 (+0.02分)**：
  - 条件：当日创20日新高（`breakout_20 >= 0`）且呈现经典多头排列（`close_ma5 > close_ma20 > close_ma60`）；
  - 逻辑：上方无套牢密集阻力峰，处于向上突破筹码真空区。
- 🔴 **阴跌大熊坑超跌反抽一票否决 (-999分注销)**：
  - 条件：处于 60 日最底部区间（`position_60 < 0.25`）且距离 60 日均线仍有 10% 以上深坑（`close_ma60 < -0.10`）；
  - 逻辑：长期下行通道中的反抽首板，每上涨一分钱都面临巨量解套抛压，次日极易被砸崩，坚决不选。

### 2. 传智教育式小市值弹性基因
- 🟢 **小市值轻装上阵奖励 (+0.015分)**：
  - 条件：流通市值 $\le 35$ 亿元（`float_cap <= 35e8`）；
  - 实测数据：全样本统计中，$\le 35$ 亿的小票首板次日晋级率为 **19.17%**，显著高于全市场平均的 **17.42%** 与 $>60$ 亿中大盘的 **17.38%**。

### 3. 板块共振与题材身位
- 🟢 **适度梯队爆发加分 (+0.015分)**：同题材池内首板数为 2~7 只，代表板块出现良性共振与低位扩散；
- 🔴 **孤勇者扣分 (-0.015分)**：同题材仅有 1 只独苗，缺乏板块效应支撑；
- 🔴 **过度高潮预警 (-0.010分)**：同题材 $\ge 8$ 只首板，防范次日板块分化兑现。

### 4. 连板生态与断板恶性闷杀防守
- 🔴 **恶性退潮熔断 (空仓防守)**：
  - 触发条件（命中 $\ge 2$ 条）：
    1. 全市场跌停家数 $\ge 8$ 家（恐慌蔓延）；
    2. 全市场炸板率 $\ge 40\%$（高位大面）；
    3. 昨日首板今日晋级率 $< 10\%$（接力中毒）；
    4. 全市场红盘率 $< 25\%$（普跌冰点）。
  - 执行：触发时直接启动现金防守，不新增首板买入，避开系统性杀跌。

### 5. 龙虎榜席位与实战竞价终审（执行层）
- 🔴 **量化主导与拉萨接盘一票否决**：
  - 盘后龙虎榜被量化高频席位（中金/华鑫/中信上海等）买入占比超 50%，或买前五被拉萨天团占据 3 席以上，次日一票否决；
- 🟢 **次日 09:25 竞价平低开生死熔断**：
  - 竞价只要开出平开或低开（$\le 0\%$），买入条件单立即注销撤单，盘中翻红一律不追，杜绝冲高回落大面。
