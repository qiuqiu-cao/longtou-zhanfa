# 限定三篇原文的经验卡

实际阅读时间：2026-10-20 15:54—15:58 UTC。检索与原文读取分开，原作者不是训练标签，本文只提取待检验关系。

1. 不谓侠的空间，2026-02-28 16:40，《断板反包实战体系：巨量阴阳辨主力，量价关系抓反包！》：https://m.tgb.cn/a/2pMJ6NKmYyq?type=hot
   - 正文提出回调深浅、回调量与前一分歧日比较、恢复关键价格、再启动量价以及情绪/题材配合。
   - 采纳为连续变量，保留破位、放量下跌和未能恢复的反例；不把一半/四分之一缩量设为优化阈值。
   - 否决以形态直接认证主力控盘、短洗盘必然快涨及未出示独立样本的胜率数字。正文与后续评论分别定时；评论不继承16:40。

2. 弈者谋势，2026-09-05 17:19，《模式在不同市场环境中的运用（9月5日）》：https://m.tgb.cn/a/2uQsLa3ivPn?type=hot
   - 正文把近期涨停史、回调量价和市场阶段结合；作者9月6—8日的补充另有时间，不能当9月5日已知。
   - 采纳历史涨停次数、历史晋级/次日反馈、回调量价与既有情绪特征的联合检验；不把多次涨停机械当作优势。
   - 否决仅凭既往上涨案例证明模式有效，或将涨停价格当作已证实的资金成本。题材历史缺项不虚构。

3. 早日赎身，2026-07-03 12:59，《炒股路上你自己一个人奋斗，你不需要任何朋友！》：https://www.tgb.cn/a/2t7Wm8XWXon
   - 作者描述持股下跌过程中，多次用缩量和洗盘解释回撤，损失随之扩大。这是自述，不认证交割或实际收益。
   - 作为反例提醒：缩量回调不能成为不失效的解释。研究保留回调破前低、未收复前板价、继续走弱的样本，不先删掉失败者。

市值：这三篇没有提供可复算的固定最优市值证据。不采纳任意小盘偏好阈值，只用历史信号日市值连续变量；历史口径及来源时点限制保留。

主动性：无合格历史逐笔/完整同题材分钟顺序。训练仅能用再启动日相对归档市场涨幅、恢复关键价格及量价反应作代理，不能声称真实先手拉升或资金带动。
