## 使用与恢复

研究CLI支持`audit / freeze / backtest / predict / settle / review`；`settle --horizon 0`比较当时身份，3/5分别比较后续角色。回测一次完成后拒绝重跑，未开始的检查点可恢复，开始后中断的拟合需审查且不自动重拟合。

```powershell
D:\python\python.exe leader_role_engine.py build --features <现有特征目录> --calendar <已核官方日历> --theme-report <同日theme/report.json> --output <新角色数据.json>
D:\python\python.exe leader_role_research.py audit --dataset <数据.json> --labels <独立盲审标签.json> --output <唯一资格报告.json>
D:\python\python.exe leader_role_research.py freeze --dataset <数据.json> --labels <标签.json> --output <唯一协议.json>
D:\python\python.exe leader_role_research.py backtest --protocol <协议.json> --output-dir <唯一回测目录>
D:\python\python.exe leader_role_research.py review --protocol <协议.json> --calendar <日历.json> --settlements <结算文件...> --output <唯一总验收.json>
```

富证据数据的每组必须包含`value/status/observed_at/available_at/source_path/source_sha256/pointer`，指向保存JSON的准确值；不能把手填身份布尔值或未来字段冒充事实。`pool/theme/path/capacity/history/competition/dependency/cycle/pressure/emotion`的必要字段在引擎的`_valid_group`集中校验。

独立审核包`blind_identity_packet.json`不含模型输出和未来结果。`identity_labels_PENDING.json`保留每个候选的全部11栏；已知标签要求两位不同审核者的匹配结论、证据路径和实际审核时间。程序只校验材料与声明，不自动认证审核者真的没有看过模型或未来。

当前`predict`要求绑定通过全类型历史门的固定模型，现有资料不满足，因此没有实际启动。`review`现阶段只验角色门，C2原固定门未接通，部署持续拒绝。
