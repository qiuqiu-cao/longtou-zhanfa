## 命令与API

来源资格附层（输出必须新目录）：

```powershell
python relay_source_qualification_repair.py --predictions <完整CSV> --audit-dir research/model_upgrade_validation/ranking_optimization_20261015T173045Z/source_audit --output-dir <新目录>
```

单字段比较的 `prepare/freeze/run` 已完成并锁定，不能再次执行来重试失败试验；只读重放可检查保存模型：

```powershell
python relay_source_feature_research.py verify
```

该verify也使用不覆盖收据，已有完整重放收据时直接查看 `execution/all16_saved_model_replay_verification.json`，不重复命令覆盖。实际入口函数：

- `relay_source_feature_research.patched_feature_copy(full, fields, verified, expected_changes)`：唯一训练/推断补特征函数。
- `relay_source_feature_alignment.predict_with_same_source_routes(test, raw_score, shape, reference)`：同源路由包装，最终7头与current6已实际使用。
- `relay_source_feature_metric_view.applicability_view(frame)`：纯展示性能适用性视图，不修改预测。

干净性能视图已生成 `metric_applicability_final/same_pool_classification_metrics_APPLICABILITY_CLEAN.csv`。PAIRWISE没有绝对事件头，除candidates/known/unknown_outcomes/positives和明确结构性UNKNOWN数量外，全部绝对性能、混淆矩阵、覆盖率和utility都N/A。**结构性UNKNOWN不表示分类失败或零收益。** 原性能表保持前像；其他分类头数值精确不变。
