# 评分展示接口

本模块只展示已经导出的研究结果。它不训练、不校准、不调用模型、不改变原方向或生产账本。新日期应由原工作台先执行完整独立审阅和原留档门，再调用此视图；本模块不能替代原工作台入口。

`relay_research_scorecard.build_scorecard(frame)` 返回每个输入候选、每个方案一行的 DataFrame。必需字段为 `date/code`，其余标准字段为 `name/boards/arm/score/ranking_score/call/current_price_shape/daily_one_word`。目标与结果字段可随输入保留，但不参与排名。

`write_scorecard(frame, output_dir, input_path=None)` 输出完整 CSV、JSON、HTML 和来源/产物哈希；输出目录必须不存在。

```powershell
python relay_research_scorecard.py --predictions <已导出预测CSV或JSON> --output-dir <新的输出目录>
```

每个日期、方案分别显示完整池、同板位、原非一字池及原非一字同板位排名。`position` 按代码稳定拆分同分，`rank` 保留并列最小名次，`tie_layer` 为分值层级；没有分数的候选不填名次，仍计入完整分母。单股/无分数不构造百分位。组内分位仅是相对名次，不是涨停概率。

`absolute_event_score` 为未校准原分类分；`absolute_event_call` 保留原事件方向。`research_ranking_score` 使用输入排序值，没有独立排序值时使用输入分数；相对第一不会自动转为正向。`PAIRWISE_DAY_RANK` 只有成对偏好，其绝对事件分数、事件方向始终为空，即使输入误带正向字段也仅另存原值，不自动采用。

原 BASE 的分数、方向、原输入排名及四类完整排名另列在 `base_*` 字段。不存在同代码 BASE 记录时保留未知。当前价型资格和原 `daily_one_word` 评价池独立列示，当前资料未知不会从原非一字评价池中删行；资格列不认证成交可行性。

实际归档回放使用既存五方案 × 完整81只，共405行。HTML 默认显示最新日期30行，日期与方案均可筛选并展开每行全部字段；选择全部显示405行，BASE筛选81行。14项测试通过，另对405行逐组独立重算排序、逐条核对 BASE 原分方向，并确认改变全部目标与有效标签不会改变任何派生字段。

HTML脚本在本地 Node 中执行验证，未进行浏览器截图或视觉验收。没有访问外部网络或读取凭据，拟合数为0。
