| 显示字段 | 含义 | 不作出的推断 |
|---|---|---|
| BASE原分、原方向、原排名 | 原BASE逐股原值，并列/全部池另列 | 不用新模型回写BASE |
| BASE 100分显示 | 100 × 原始0至1分类分；标记“原模型评分，非概率” | 不称涨停概率；越界或未知不补分 |
| 绝对分类分、原方向 | 现有分类头原值及PROMOTE/FAIL/UNKNOWN | 不按名次改方向 |
| 研究排序值 | 同日同方案内的相对排序 | 不跨日期比较，不自动转为正向 |
| PAIRWISE偏好 | 成对排序研究值 | 绝对事件分、100分显示、方向均为空；无偏好分不借分类头补分 |
| 冻结分类头附列 | PAIRWISE输入中保留的冻结CORRECTED分类头信息 | 不冒充PAIRWISE事件方向 |
| 完整池、同位、非一字、非一字同位名次 | 完整分母、有效分数量、代码序、并列层级及分差 | 无分数不伪造名次；未知候选不删行 |
| 单股结构位置 | `sole_candidate_position=1`表示唯一候选 | 不生成偏好值、组内分位或正向结论 |
| 原价型与核验附层 | 原current_price_shape和verified_current_price_shape分栏 | 附层包含原已知值保留，不能把全部行称本轮新增核验 |
| 补资料后研究方向 | 仅两个CORRECTED分类头的76条同日已存B分复算 | 不称原预测或事前成功；BASE、旧双通道与PAIRWISE不转换方向 |
