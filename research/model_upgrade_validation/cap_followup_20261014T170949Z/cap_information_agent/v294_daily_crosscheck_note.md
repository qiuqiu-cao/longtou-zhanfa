# 旧 V294 与直接日线 VWAP 的无目标交叉核对

本批只加载无目标特征与无目标来源卡，日期／代码严格匹配。测量前冻结 1e−6、1e−4、0.001、0.01、0.05 五个容差。没有读取 V294 目标标签，没有拟合，没有选择预测效果最好的字段、函数或阈值。

**结论：共同已观察值近乎一致，日线方案的实质变化是缺失覆盖及更早历史覆盖，而不是修正旧 VWAP 数学估计。** 不能再把“旧报告写 interval means”解释为旧代码用 OHLC 平均价；实测旧新比值吻合。

原 V294 全部 2,888 行均在原 9,245 候选池中，日期、代码、板位与价格一致。旧 roster、原全池及未知都没有删除。

| 旧 2,888 行口径 | 行数 |
|---|---:|
| 旧 VWAP 特征有值 | 1,915 |
| 日线比值可重建 | 2,886 |
| 两者共同有值 | 1,913 |
| 旧有值、日线未知 | 2 |
| 旧未知、日线有值 | 973 |
| 双方未知 | 0 |

973 个新覆盖包含 888 条 Sina 日线，以及 85 条 9 月 ×100 成交量单位假设；后者仍单列“单位假设”，不因旧特征对上而自动认证独立来源单位文档或严格原取得时点。

共同 1,913 行的 `(close/VWAP−1)` 绝对差中位数 1.850e−9，99 分位 1.775e−6，最大 9.606e−6：

|---|---:|---:|
| 1e−6 | 1,885 | 28 |
| 1e−4 | 1,913 | 0 |
| 0.001 | 1,913 | 0 |
| 0.01 | 1,913 | 0 |
| 0.05 | 1,913 | 0 |

相对 `close/VWAP` 比值差的计数也逐项相同。绝对比值差乘 100 才是百分点；表中数值是小数尺度，不将其错称百分数。

共同 Sina 历史 1,816 行中，1,815 行差不超过 1e−6，全部不超过 1e−4，最大差 1.306e−6；共同 9 月 97 行中，70 行在 1e−6 内，97 行全在 1e−4 内。

原 9,245 分母按同样日线可观察政策共有 9,102 行有值、143 未知；相对旧 roster 加上旧缺失，共 7,189 行是“旧未有值、日线有值”，其中 6,216 行完全位于旧 2,888 roster 之外。较早历史补全是真实来源覆盖增加，但不是新增经济假设，也不是增益证明。

这项交集证据补足了 `novelty_note.md` 中的第一步缺口：**不支持精度修复理由，支持覆盖修复理由。** 如果以后形成新固定比较，应围绕“同一价格相对均价假设在较完整历史覆盖下是否改善分类”表述；必须把旧 V294 失败和重复研究背景放入协议，维持完整成员及一次性门，不冒称全新盘口因子。当前仍没有数值验收或部署授权结果。
