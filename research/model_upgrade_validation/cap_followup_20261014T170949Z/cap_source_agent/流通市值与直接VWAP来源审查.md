# 流通市值与直接 VWAP 来源审查

本批只审查已有档案，没有拟合、查看新字段的标签效果、采集新行情或修改原预测。原始候选、标签、分数、模型、登记和定时任务保持。`cap_source_findings.json` 保存完整来源哈希、逐源时点、口径和检查数字。

## 来源结论

**历史市值确实可回溯到逐日日线；不能断言它把当前股本倒套全部历史，但也不能认证它具有原时点的股本真值资格。**

冻结预处理共 9,245 条、684 个信号日、2,080 个股票代码，日期/代码没有重复。9月前原 9,063 条全部与 V16 逐日来源精确匹配，收价、流通市值及换手百分比转小数一致。8,920 条市值为正，143 条缺市值；9月原 182 条全部缺市值。完整对应表包含全部未知，不缩小候选池。

原 `leader_system_v3.py` 的实际 SHA 与重建前收据一致，其流程是：Sina 不复权日线中的 `outstanding_share` × 收盘价 → `float_cap` → 候选 `signal_float_cap`；`float_cap_log = ln(max(float_cap, 1))`。市值量纲为人民币元，对数使用自然对数；日线换手保存百分数，候选换手除以 100。Eastmoney 日线分支直接把市值设为 NaN；腾讯恢复的退市日线也未提供市值，不能补成 0。

V16 原重建说明 `generated_at_utc = 2026-09-06T04:26:52.314830+00:00`。本批实际逐字节核验其保存的两份日线和候选 SHA 全部一致。原预处理 joblib 的 SHA 也与拟合前收据一致。候选 `source_timestamp` 的“信号日 15:00”是程序赋予的市场时点，不是原 HTTP 收件证明；股票资格的时点核验也不等于流通股本时点核验。

## 股本、单位与公司行动

当前安装的 AKShare `stock_zh_a_daily` 实现请求**带日期的供应商股本序列**，按日期外连接、向前填充，再把万股乘 10,000 转成股。所检查的实现没有把当前股本向后填充全部历史的步骤。这个当前库的版本和源码哈希已经保存；**没有将当前实现冒称原采集时完全相同的库版本**。

两份 V16 日线共有 1,975,903 条正市值。用市值/收价得到的隐含股本，在 3,050 个有值代码中有 2,304 个跨日变化；高于 1 ppm 的跨日变更共 12,258 处，全部另存。这与“所有股票只使用当前固定股本回填历史”的说法不符，但变更日期是否准确、是否包含后来修订，仍未知。

在可观察的 1,975,894 条日线上：

\[
\frac{\text{市值}}{\text{收价}}=\frac{\text{成交量}}{\text{换手率小数}}
\]

全部在相对误差 `1e-10` 内一致，最大误差约 `4.00e-15`。这是同一个股本分母进入两条派生公式造成的恒等关系，不能当独立股本真实性验证。

股本的原 HTTP 响应、原发布日期/生效日序列和修改历史未保存在 V16 CSV 中；原 `outstanding_share` 列在换算后被丢弃。日线不复权声明不负责证明流通股本的解禁、送转、发行、回购等处理正确。当前只能确认所保存的日期序列会变化，不能给每一次变化指认公司行动或确认当时可知。

## 直接 VWAP 的额外检查

按要求仅检查已有成交量、成交额及 OHLC，未测其晋级区分效果。

原9月前有 **8,920/9,063** 条 Sina 候选可直接重建 `VWAP = 原日线成交额 / 原日线成交量`。8,920 条全部落在原日线低价—高价范围内（允许 0.01 元报价差）。143 条保持缺失。

原9月 182 条全部精确匹配既存 V278 腾讯不复权 `day` 原响应。139份原响应哈希和标准化重建全部通过。用原候选成交额除以腾讯原成交量：按“股”单位 0/182 落在 OHLC 范围，按“100股/手”单位 **182/182** 落在范围，原收价也全部在 0.011 元内一致。×100 是强一致性推断；原 V278 解析器没有保存成交量单位声明，不能将该推断包装成独立官方单位核验。原 V278 有请求开始时间但真实收件时间为 null，不能回填。

若股本分母相同，则：

\[
\frac{\text{市值}\times\text{换手率小数}}{\text{成交额}}
=\frac{\text{收价}}{\text{成交额}/\text{成交量}}
=\frac{\text{收价}}{\text{VWAP}}.
\]

历史8,920条全部验证此式，最大绝对差约 `2.58e-13`。9月供应商市值/收价与“腾讯成交量×100/换手率”的隐含股本也接近，182条最大相对差 `1.12e-5`，与有限精度字段一致，但不认证公司行动真值。因此，该比值的解释应是**收价相对日内成交均价的位置**；不能解释为资本结构之外新得到的一份独立“市值与换手配合”信息。

直接VWAP可减少股本日期处理问题，属于可明确研究的观测候选；它与上述市值比值是同一个信息方向，不应当作两个独立改进累加。本批未证明它相对原29字段有新增预测效果。全9,245条中，8,920条历史直接值、182条9月单位推断值、143条缺失分栏保存；严格原时点和完整跨源单位资格没有自动通过。研究可以在明确当前知识截止、事后诊断性质及剩余未知的前提下另批固定评估；本批不授权直接部署或声称严格来源门已经满足。
