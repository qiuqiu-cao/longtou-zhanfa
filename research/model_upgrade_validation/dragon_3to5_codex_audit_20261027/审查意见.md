# Gemini 三板到五板模型审查意见

审查时间：2026-10-27。审查对象为 `dragon_3to5_breakthrough_20261027T064500Z` 原报告、模型、manifest、1480 行留出预测、340 日选股摘要及相关训练脚本。

## 结论

Gemini 确实完成了独立模型拟合、保存和一组按时间分折的历史预测。保存的模型可以加载，原预测中的 AUC、Top1 命中数可以复算，BASE 模型文件哈希与原冻结记录一致。

但当前只能认定为存在初步排序信号的研究版本。标签处理、预处理和训练截止时点存在具体错误；BASE 对照不是同期间的样本外对照；报告还有多项数字不一致及无证据的原因解释。因此“严格无未来函数”“跨周期极其稳健”“稳定提升”“六大标签联动生效”等表述没有被当前产物充分支持。不能据此认定达到生产或实盘使用标准，也不能认定已证明优于或劣于 BASE。

本次仅审查并追加独立产物，没有训练、调参、修改 Gemini 原文件或替换 BASE。用户此前允许 Gemini 独立推进，因此本次不把“未经过 Codex 事前审查”当作问题。

以下均沿用原预测文件及原标签，只是复算，不是完成修正后重训的成绩。

| 指标 | 复算值 | 含义和限制 |
|---|---:|---|
| 全历史三板样本 | 1851 只次，599 个信号日 | 2023-11-30 至 2026-08-31 |
| 四折留出预测 | 1480 只次，449 个有三板股的信号日 | 尚存在下述泄漏和标签错误，不能称严格盲测 |
| 原标签全池到五板比例 | 329/1480 = 22.23% | 混入未知当失败，须修正 |

| 竞争日前两名个股到五板比例 | 184/680 = 27.06% | 是逐只命中率，不是“前两名至少一只成功”的日期比例 |

公平的“每日随机选一只”基准应先逐日求成功比例，再对日期等权平均。340 个竞争日这一基准为22.8948%，第一名相对改善8.8699个百分点；原报告用候选行加权22.5383%计算出9.23个百分点，两者权重不同。“Alpha”在这里最多指命中率差，不能当投资收益超额。

## 二、需要先修正的问题

### 1. 未知高度被错误当作失败，且已有成功被错标

训练脚本第30行直接执行 `(terminal_board >= 5).astype(int)`。NaN与5比较为False，8条右删失记录全部成为0。原报告声称保留未知，但实际标签没有保留未知。

按已归档完整池和官方交易日网格，沿三板当日及次日的 `promoted_next_day` 逐步核对：

- 2026-08-26 海鸥住工002084：随后两个官方交易日已连续晋级，五板目标为1。
- 2026-08-27 捷荣技术002855：已连续晋级，五板目标为1。
- 2026-08-27 万向德农600371：已连续晋级，五板目标为1。
- 另5条五板目标仍未知，应保留未知，不能当失败。

原因是原 `terminal_board` 要等整个连板序列最终结束才能赋值，但本任务在已经走到五板时即可确定成功，不必等最终高度。三进四也应使用精确下一官方交易日的晋级标签，不能用可能右删失的最终高度代替。

现存1480行预测中，按上述档内路径核验有1475条五板目标已知，其中332条成功、5条未知。此为标签诊断，不是修复后模型成绩。3条改正成功均未被原竞争日Top1选中，因此不能声称标签修正使模型多命中3个第一名。

独立复核仅使用项目既存档案，未对历史行情重新进行全量外部来源鉴真。

### 2. 全期中位数进入了更早日期的特征

`train_and_backtest_dragon_3to5.py:33`及第34行，在切分四折以前用整个1851行计算价格、市值中位数。`run_two_arm_experiment.py`和`compare_two_arms.py`也存在相同处理。

例如第一折训练期的对数市值中位数为21.99458，全期中位数为22.48352。用全期门槛替代训练期门槛，会改变第一折103条训练样本、99条测试样本的“小市值”标记。价格标记也发生改变。这是可直接确认的预处理泄漏，影响大小需要修正后重新评价，不能直接估算。

应逐折仅用训练数据计算门槛并固定，再应用到测试和未来日期。最终模型还应随模型保存固定门槛；当前特征函数如果对一个新日期或单只股重新计算中位数，特征含义会变化。

方法依据：[scikit-learn 数据泄漏与预处理说明](https://scikit-learn.org/stable/common_pitfalls.html)。

### 3. 只限制信号日期，没有限制标签成熟日期

训练行只用 `date <= train_end` 选取，没有检查当时是否已经知道结果。按两日目标真正可确定的日期核验，四折分别有2、4、3、2条训练记录的目标需在测试期才知道。原模型提前使用了这些结果。

例如2024-08-30的三板股，下一交易日为2024-09-02，训练截至8月31日时不能提前知道其是否断板；2025-05-30的部分样本需到6月初才能知道是否到五板。

修正应以“目标首次可确定日期”限制训练资格：三进四失败可在下一交易日确定；通过四板后，五板成败在再下一交易日确定。仅因完整终点在未来不一定构成五板标签泄漏，例如五板已在训练截止前出现的股票，其五板成功当时已经可知，不能机械剔除。审查CSV同时保留完整终点和两日目标时点，避免混淆。

### 4. BASE对照使用了未来训练版本

`compare_two_arms.py`直接加载当前冻结BASE，评分2024-09至2026-08整个历史。

原BASE manifest明确：`training_max_label_date = 2026-08-31`，模型于2026-10-07形成。因此33.82%（115/340）虽然可以复算，却不是这些历史日期上可获得的样本外BASE成绩。不能据此认定它优于31.76%的新模型，也不能据两个数字证明结合使用有效。

应优先使用与各测试窗匹配、当时仅用成熟历史标签训练的既存BASE分折预测；若没有，应将此比较明确标为回看诊断，另立公平基准。旧BASE模型文件仍保持冻结，不为修复对照而覆盖或改写原模型。

### 5. 市场情绪已经入模，题材情绪与真实封板细节仍未建立

53个特征包含市场梯队、情绪、换手、成交和日线形态，因此并非完全没有研究情绪。但数据实际覆盖为：

- 全1851条的 `theme`、`theme_support` 均为空，没有逐股题材群体扩散证据。
- `first_seal_minute`、`last_seal_minute`、`bomb_count` 仅557条非空，非空值都只有0，不能当完整真实封板时间或炸板证据；这些字段也没有进入最终53特征。
- `sealed_fund_float_cap` 全空。
- 减持、解禁、业绩三个风险字段全1851条为0，不能据此证明历史上均无风险。

`firm_seal_strength` 实际由一字代理和日振幅计算。它是形态代理，不等于已经核实早盘主动封板、尾盘小单回封或筹码派发。三板六类标签和竞价闸门没有接入本训练及留出排名的计算，报告写规则不等于过滤后的模型成绩已被验证。`audit_three_board_traps.py`也未被训练器实际调用。

## 三、报告表述与产物不一致

| 项目 | 原报告 | 保存预测/manifest复算 |
|---|---|---|
| 四折测试样本数 | 250/386/494/350 | 433/277/326/444 |
| Tier2成功数 | 52 | 43 |
| Tier3成功数 | 65 | 68 |
| Tier4成功数 | 77 | 83 |
| 竞争日平均候选数 | 3.47 | 1371/340 = 4.0324 |
| 竞争日最大候选数 | 14 | 34 |
| Top1三进四失败 | 131 | 原标签为133；不能称均直接跌停 |

原报告把99条“四板后未到五板”解释为监管函、筹码松动或特停担忧，把147个无五板赢家的日期直接称作退潮共振，把漏选归因为盘后题材爆发。当前产物没有逐案公告、题材和分时证据，不能确定这些原因。阶段结果可以统计，原因必须另核。

56%来自108/193，分母只保留事后已知至少有一只走到五板的竞争日。可以作为条件捕获率诊断，但不能当实际每日选股命中率，更不能用于事前筛去147个没有赢家的日期。

2024/2025/2026原Top1率为45.59%/31.28%/22.58%。相对基准的改善不等于绝对命中率稳定，也不能单凭这张表证明适应所有市场情绪阶段。没有校准与独立验证，输出应称未校准分数及历史命中率。方法依据：[scikit-learn 概率校准说明](https://scikit-learn.org/stable/modules/calibration.html)。

`run_two_arm_experiment.py`与`compare_two_arms.py`还使用了不同的线性对照参数，并都写同一个`two_arm_comparison.json`。本次保留并绑定当前原件哈希；原实验历史、执行收据和真正未参与选模的测试期需补齐，不把当前四折直接认证为未被探索过的最终盲测。

## 四、参与性仍需单独验证

原竞争日Top1中178只三板当日为一字代理，但其中162只非一字Top1只命中37只五板。不能只用总31.76%来描述可换手参与者。

按现存次日日线代理，原Top1中89只次次日为一字涨停；63只次已知次日开盘不高于昨收，另1只次开盘缺失。后两项对应用户竞价取消要求时仍需实际09:25数据核验，不能以次日日线开盘假冒完整竞价成交和未匹配量。各类限制可能重合，不能简单相加。

这些只是执行限制的诊断统计，不是实际成交单，也未计算扣费收益。还没有证明六标签、BASE资格门、09:25取消、盘中触发之后能保留多少候选、命中与收益；取消也不能自动换买下一名。

## 五、给Gemini的返修要求

先修正现存实验，保留原始产物和本次审查前像，不急于增加算法或继续调参：

1. 用精确官方交易日的两次连续晋级构造目标，明确成功、失败和未知，修正3条已知成功及5条未知。
2. 每折仅用训练期估计并保存预处理门槛，训练资格检查标签实际成熟时间。
3. 使用合法的逐折BASE对照或标明没有公平BASE对照；补每日等权随机基准和简单排序基准。
4. 保持既定模型和参数，先做一次明确记录的技术返修复算，不按修复结果再次选阈值；记录所有已探索配置，承认旧测试已被查看。
5. 报告从结果文件自动生成，保留完整日期、失败、未知及Top1/Top2两种口径；补非一字、六标签资格和竞价执行影响。历史字段不足就说明不足，不用日线形态编造真实封板行为。
6. 修复通过后，明确哪些效果仍须后续未用于调参的数据或新日期前向观察验证。当前不据本次审查部署或自动交易。
