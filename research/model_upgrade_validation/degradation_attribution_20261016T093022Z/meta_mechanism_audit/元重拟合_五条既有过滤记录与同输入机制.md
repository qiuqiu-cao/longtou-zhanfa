# 元重拟合：五条既有过滤记录与同输入机制

本次只读取已保存的2025年11月个股上下文PREFIX/FINAL二级模型、完整第三块OOF及原5条已过滤记录；拟合0、网络0，没有计算PREFIX在外月的整体效果，没有选择或推荐新阈值，也没有读取10月16日市场结果。所有解释是模型算术归因，不是资金因果。

## 可以直接证实的原因

**最终重拟合改变了条件分数函数，而非仅统一挪动截距。** 同一份输入、同一组10字段，PREFIX和FINAL给出不同结果。原5条过滤记录在既有阈值0.3处，只有国风新材因重拟合从阈值上方降到下方，新增被过滤；另外4条在PREFIX下原本就低于0.3。国风为原已知晋级，因而该样例能够证明最终重拟合对这一个额外漏判有直接算术贡献。它不能证明全体外月效果，更不能据5条被选中的记录估计普遍误伤率。

## 填补、标准化、系数与截距分别做了什么

两个模型的imputer中位数部分改变，但原5条及第三块86个合格正向的10字段全部无缺失；两模型缺失指示维数也均为0。因此本次91个同输入记录的填补变化贡献**严格为0**，不能把退化归因于这些行的NaN或填补值。

在标准化坐标下，模型为 `logit分 = 截距 + Σ 系数×标准化输入`。本次将每特征变化对称分解：

- 标准化贡献＝两模型系数均值×标准化输入之差。
- 系数贡献＝两模型标准化输入均值×系数之差。
- 另加截距差；两项交互被对半分配，恒等式逐条闭合。

该分解不依赖先更新标准化还是先更新系数的顺序，但仍是一种明确的算术约定，并非训练机制的独立因果效应。另将标准化、系数、截距三组的6种更新顺序全部平均，对sigmoid内部得分变化留了完整Shapley算术表；拼接部件只作解释，没有训练或启用混合模型。

| 记录 | 截距贡献logit | 标准化贡献logit | 系数贡献logit | 填补贡献 |
|---|---:|---:|---:|---:|
| 闽东电力 | +0.064504 | −0.007112 | −0.044506 | 0 |
| 洪兴股份 | +0.064504 | −0.006157 | −0.145446 | 0 |
| 摩恩电气 | +0.064504 | −0.011227 | −0.141821 | 0 |
| 中利集团 | +0.064504 | −0.014357 | −0.175976 | 0 |
| 国风新材 | +0.064504 | −0.022798 | −0.094937 | 0 |

FINAL截距从−0.435767变为−0.371263，统一**推高**logit，抵消部分下移，并非导致这4条分数下降的方向。对这几条，系数变化的负向贡献大于标准化变化；闽东的正截距抵消后反而略升。国风精确合计约为 `+0.064504 −0.022798 −0.094937 = −0.053231` logit，再经sigmoid成为分数约−0.011163。

## 第三块同输入比较的严格边界

PREFIX训练341行，135正/206负；FINAL训练427行，176正/251负，新增恰为第三块86个合格正向（41正/45负）。前缀训练最大目标7月25日，第三块从7月28日开始；FINAL最大目标10月31日，均早于11月1日外月截止。成员核验通过，没有把日期越界当本次解释。

第三块完整原B为562行，二级只对其中86个原合格正向出分。对这86份完全相同输入，PREFIX内部得分均值约0.423211、FINAL约0.441153；个体变化范围约−0.083933至+0.075590。它们表明函数形状和位置都变化，不能只称“整体降低置信度”。**PREFIX对第三块用于选阈，FINAL已经把这86条及其标签用于训练。二者不是同定义的泛化对照，本报告没有比较其准确率、Precision或校准优劣。**

原阈值0.3在PREFIX选阈尺度形成，最终仍沿用。模型重拟合后，同输入数值变化已被直接观察，阈值迁移风险确实存在；它是否是整个研究退化的主要原因，必须由另行冻结的完整研究检验。本样例不提供NO_META_REFIT整体收益或效果结论。

## 尚不能辨识的部分

1. 无法仅凭两份拟合结果，将系数变化唯一归因于新增样本的类别比例、特征分布、相关结构、噪声或有效正则变化。训练行数由341增至427、正例比例也变化，C保持1且每行权重1；这些因素同时变化，未作受控拟合消融。
2. 标准化截距与原单位有效截距依坐标定义而异。不能只取某一坐标的截距变化讲因果；本次已同时导出均值、尺度、标准化系数和原单位斜率。
3. 已被原FINAL过滤的5条不是独立随机样本。国风边界跨越可证，PREFIX在全外月是否更准、是否会新增其他误报或漏判尚未计算。
4. 没有新增真实题材、父锚或盘口证据；同输入算术不能认证资金博弈原因、角色身份或事件概率。
