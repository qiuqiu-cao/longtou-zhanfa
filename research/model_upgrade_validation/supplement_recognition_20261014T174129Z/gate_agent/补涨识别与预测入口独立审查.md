# 补涨识别与预测入口独立审查

本审查只读既存源码、标签、原判断和已核来源；没有获取新资料、创建标签、拟合或修改共享模块。实际来源字节摘要、完整15只和完整10只独立复算见 `read_only_gate_findings.json`。交易日期以下按A股北京时间定义。

## 可修的漏识别根因

1. `leader_role_engine.py` 的 `dependency` 合格条件强制 `same_specific_theme is True`；旧 `SUPPLEMENT` 又要求 `theme` 和 `dependency` 两组。跨行业名称情绪补涨即使有实际原文和跨日时序，也不能诚实地塞入这个旧定义。必须新增类型明确的父锚—子股关系候选层，不伪造“同具体行业题材”来打开旧门。
2. 当前 `v217` 字形簇依赖当日收盘/炸板范围，至少4成员、2连板、2板位、3行业。14日主板仅百洋、阳光两只字形命中，九阳已离开连续涨停池，原实际 `cluster_count=0`。单日簇广度并不能替代跨日情绪锚连接。只降低成员阈值仍解决不了父锚退出当前池的问题，并容易制造同名误报。
3. 原角色解释只补到报告附页，尚未形成可核回放的关系图和完整竞争范围；“百洋偏晋级”恰好判断对，并不说明它先前识别了补涨逻辑。原13日支持文确实遗漏九阳关系，14日原百洋角色仍写“饲料四板情绪锚”。

建议现在接入的不是手工加分，而是来源绑定的关系诊断：指定原历史父锚范围、全当前子股范围、关系类型、原文范围、起板先后、父锚阶段/断连时刻、子股当时位阶、同链对手和替代解释。每只包括未连接、未覆盖、来源失败、名字相似但无已核叙事等状态。父锚可以是已在指定历史范围内的旧高标，不要求它仍涨停。

## 实际案例应如何进入卡片

九阳→百洋：限定原文已有“羊/阳/洋”叙事；10月9日九阳5板/百洋首板，12日6/2，13日旧锚断连/子股3，14日旧锚未续板/子股4且一价。兼容较早启动、旧锚断连后延续的候选。不能进一步认定唯一父龙、资金迁移因果或正式补涨龙身份；魚粉/农业等独立解释保留。来源实际取得在14日，不能说13日原独立判断已经掌握这份关系。

九阳→阳光：9月30日曾首板，之后中断；13日旧锚断连节点重新首板，14日2板且非一字。应归入旧跟风修复/节点候选，与百洋的早启动领先阶段分开。当前较新14日“阳光套利九阳”与“阳光胜冰山”页面正文取得失败，不能记为已核作者原文。9月30日既存正文证明消费/名称叙事存在，尚不足以验证14日真实父子因果。

不能据名称关系把冰山和阳光设为必然相互淘汰。完整二板对手11只（自身加10对手）、跨板位百洋和旧锚九阳反馈都应显示；共同晋级、共同失败、分化均保留。字形反例华阳国际、华阳新材、澳洋健康13日也在同匹配池，14日未封且日线为负，说明名称发现只能召回候选，不是正向晋级规则。这些是原范围内的行情反例，不是三条独立补涨身份负标签。

## 标签与拟合资格

实际原标签101695格中，HEIGHT9245已知（995正、8250负）；其余10类各9245未知，SUPPLEMENT独立真值为0。原9178有效晋级标签回答“次日是否延续连板”，不能回答“是不是补涨龙”。实际保存3707条历史分数只有HEIGHT，其他10头均缺；既有C2要求全部11头合法时间样本外分数，因此真实接纳0，C2尚未拟合。名字、板位、晋级结果、作者宣称或当前候选状态均不能填入监督补涨标签。

这里不把角色标签门扩大为所有晋级研究的禁止。若一个未来的晋级挑战仅使用可核的事前关系事实、以原有效晋级标签学习，不必先拥有SUPPLEMENT身份真值；但仍须有原训练窗完整同口径关系来源、知识截止和覆盖。目前只有少数新取得案例，未具备这个输入资格，所以本批不应拟合。

## 可执行评价契约

评价单位固定为 `signal_date + scope_id + anchor_code + child_code + relation_type + knowledge_cutoff`。候选发现、证据关系成立、身份识别、次日晋级、实际可交易性分别结算，不用后面的结果替代前面的标签。

- 候选发现：保存声明范围内所有子股、既存父锚集、生成/未生成边、相似名称对照、所有竞争边和未知。完整母集可以限定档案范围，但须明确范围；不冒充全市场完整。
- 事实关系：分别审计已绑定原文联系、先后时序、父锚断连后子股延续、同链当下相对领先。这些是有限事实目标，不是资金因果。正文/作者回复/评论单独保留时点；搜索摘要与正文失败保留为线索。
- 身份真值：用真实独立审阅和被审阅的资料范围形成候选/核心/未知，分清父锚身份和子股身份，保留替代父锚和多关系。当前审计不制造标签，也不能自动声称盲审。原正式角色身份门继续两份独立实际审阅及必要资料资格。
- 召回评价：只有完整独立审计的有限边集才能当召回分母；未提到、未覆盖、搜索失败均不是负例。正式Identity报告全池Accuracy、完整正例Recall、Precision、F1、弃判和证据覆盖；Top1/Top3按完整同链竞争，缺边/缺分保留，允许并列，不强制一个赢家。
- 晋级评价：固定相同日期、股票、标签的完整候选与冻结BASE配对，报告Accuracy、完整Recall、Precision、F1、覆盖、板位、真实一字和关系证据分层；保留方向未变和方向变坏的全部股票。严格历史时点缺口与今日知识截止下历史诊断分别注明。
- 时间评价：D+1晋级是行情目标；D+3/D+5身份延续需要独立角色标签，不从涨停机械产生。第一次观察失效、此前最后确认和后续重新领先分开，观察时刻不冒充精确失效时刻。
- 数值比较：来源具备后，另批固定一个基准、至多两个挑战、30分钟、原全部效果门。失败不改参数重跑，不把已看案例称新盲测；原120日前向门保持，单次百洋/阳光案例回放不授权替换。

本批可交付的实际提高，是把遗漏的跨行业补涨关系变成有源、可回放、完整竞争的识别输入，并实际展示于独立判断和评分冲突输出。预测能力是否提高须新记录到期检验；当下没有可以诚实报告的增益。
