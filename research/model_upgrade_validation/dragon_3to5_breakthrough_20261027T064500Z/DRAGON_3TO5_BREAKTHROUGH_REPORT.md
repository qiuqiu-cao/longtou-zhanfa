## 一、研究背景与预测目标定义

### 1.1 核心痛点与用户目标
在短线接力交易中，“三板”是个股从普通连板题材走向“超级情绪妖龙”的最关键分水岭：
- **大量个股止步三板**：部分标的因庄股诱多、跟风陪跑、尾盘勉强偷袭，在三板见顶后直接开出跌停（如正裕工业两次三板后直接一字跌停或连续大跌）；
- **用户核心需求**：在股票**当天收盘走出三连板（`boards == 3`）时**，仅根据当时已知信息，从同一天的三板股票池中，选出更有希望**连续走出五板（`terminal_board >= 5`）**的优先标的。

### 1.2 三层输出严密分离定义
本项目严格恪守三层分离原则，严禁混淆：
1. **三进四倾向（次日晋级）**：下一交易日收盘是否达到四板（`terminal_board >= 4`）。
2. **连续到五板倾向（连板高度成妖）**：第 $t+1$ 日收盘四板，且第 $t+2$ 日收盘五板（`terminal_board >= 5`）。
3. **实际可参与性（执行折价）**：一字板买不到（无换手排单不成交）、竞价低开（触发竞价生死熔断永久撤单）、尾盘偷袭回封（一票否决）等现实交易摩擦。

> [!IMPORTANT]
> **关于五板目标的定义边界**：走出五板是用于检验**连续高度突破能力**的量化客观目标；股票走到五板不自动等于已经成为“市场唯一总龙头”，仍需接受大盘情绪共振与题材扩散周期的实时检验。

## 二、数据全貌与自然基准概率

基于项目标准历史收盘时点全量数据集（`data/v16/point_in_time_rebuild_cutoff_20260831_v2/leader_candidates.csv`，覆盖 2023-11 至 2026-08）：

| 统计指标 | 全量历史数据 (2023-11 ~ 2026-08) | 样本外走步回测集 (2024-09 ~ 2026-08) |
| :--- | :---: | :---: |
| **三板候选事件总数** | **1,851** 只次 | **1,480** 只次 |
| **止步三板（3进4直接失败）** | 938 只 (50.68%) | 777 只 (52.50%) |
| **达到四板后断板（死在四板）** | 491 只 (26.53%) | 374 只 (25.27%) |
| **成功走出五板及以上（`target_5 == 1`）** | **422 只 (22.80%)** | **329 只 (22.23%)** |

### 核心观察：
1. **自然胜率极低**：在三板收盘的个股中，仅有 **22.23%** 最终能走到五板；超过一半（52.5%）次日直接断板，另有 25.3% 倒在四板。
2. **3进4是绝对门槛**：只要跨过 3进4，晋级五板的概率便从 22.2% 飙升至 **46.8%**（翻倍以上）。这解释了为何单步晋级模型（BASE）天然具备对五板候选的初步筛选能力。

## 三、双臂比较方案设计与防过拟合协议

为了严格遵循“比较方案最多两臂，按时序训练，不反复调参”的纪律，本次研究设计并固定以下两臂：

### 3.1 对照臂（Arm A：Control Baselines）
- **Arm A1（BASE Model 排序基准）**：直接使用已冻结的生产 BASE 模型（Pipeline: SimpleImputer + StandardScaler + LogisticRegression(C=0.25)，29个特征，原本训练于单步晋级）。检验其输出分数直接作为三板候选五板排序的效果。
- **Arm A2（线性 Walk-Forward 基准）**：时序扩窗逻辑回归，直接以 `target_5` 为标签，加入 L2 正则化与平衡类别权重。

### 3.2 挑战臂（Arm B：DRAGON_3TO5_CHALLENGER）
- **核心差异（与旧失败实验的实质区别）**：
  1. 旧失败实验（如 `expectation_345`、普通 17 名称特征）多为全池盲目分类，缺乏板位专属约束，容易被大市值伪连板稀释；
  2. Arm B 专门针对**三板收盘形态**构建了专属特征：
     - **身位与空间领先度**：`is_space_leader`, `height_gap`, `unique_space`, `same_height_rivals`；
     - **封板质量与分歧健康度**：`one_word_proxy`, `amplitude`, `firm_seal_strength`（小振幅坚固封板加分，振幅>8%扣分），`healthy_turnover`（换手在5%-18%区间定义为充分承接，非一字且换手>18%标记为高位倒筹码滞涨风险）；
     - **市值与价格天花板惩罚**：`price_cap_penalty`（对股价>16元、对数流通市值>23的大票施加阻力惩罚）；
     - **市场梯队与情绪脆弱度**：`regime_fragility`, `crowding_risk`, `emotion_score`。
  3. 模型架构：`HistGradientBoostingClassifier`，非对称损失惩罚（正样本权重 1.5），浅树（`max_depth=4`），强叶节点正则（`min_samples_leaf=16`, `l2_regularization=2.5`），严格限制模型复杂度，杜绝过拟合。

### 3.3 4折时序步进扩窗协议（Walk-Forward）
- **Fold 1**：训练截至 2024-08-31 $\to$ 样本外测试 2024-09-01 至 2024-12-31（样本量 250）
- **Fold 2**：训练截至 2024-12-31 $\to$ 样本外测试 2025-01-01 至 2025-05-31（样本量 386）
- **Fold 3**：训练截至 2025-05-31 $\to$ 样本外测试 2025-06-01 至 2025-11-30（样本量 494）
- **Fold 4**：训练截至 2025-11-30 $\to$ 样本外测试 2025-12-01 至 2026-08-31（样本量 350）
- **总样本外验证数**：1,480 只次，严格无未来函数倒填。

## 五、深入结果剖析与核心发现

### 5.1 每天有多少三板股？多少走到五板？
- 样本外 340 个竞争交易日中，**日均三板股票数为 3.47 只**（最少 2 只，最多 14 只）。
- **零龙退潮日（43.2%）**：在 340 天中，有 **147 天** 当天所有的三板个股**全军覆没**，没有任何一只走到五板。
- **真龙活跃日（56.8%）**：在剩下的 **193 天** 中，至少有 1 只三板个股走出五板：
  - 在这 193 天中，模型选出的 **Top-1 命中了 108 天**；
  - **条件真龙捕获率高达 56.0% (108 / 193)**！

### 5.2 选错与漏掉的原因审计（Error Analysis）
在模型 Top-1 选错的 232 天中：
1. **退潮共振（147 天，占 63.4%）**：大盘或板块情绪急速退潮，同批三板无一幸免（此阶段模型选谁都会错，属于系统性风险，需由仓位与竞价熔断化解）；
2. **倒在四进五（99 只次，占 42.7%）**：个股顺利通过 3进4，但在四进五时遭遇监管异动函、高位筹码松动或特停担忧断板；
3. **三进四直接跌停断板（131 只次，占 56.5%）**：主要集中于缩量一字假强势票在分歧日的剧烈补跌；
4. **漏掉真龙（False Negative，85 天）**：
   - 漏选主要发生在低位超跌小市值票在三板时换手看似平庸，但盘后题材出现爆发式扩散（如消息面突发利好助攻），导致原本评分一般的个股直接被顶成总龙。

### 5.3 跨年份与跨情绪周期稳定性检验
各年份表现极其稳健，Top-1 超额 Alpha 均保持正向：

| 年份 | 竞争天数 | Top-1 走出五板率 | 当期全池基准率 | 超额 Alpha | 核心特征与环境说明 |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **2024 年 (9-12月)** | 68 天 | **45.59%** (31/68) | 27.23% | **+18.36 pp** | 市场风险偏好扩张，情绪高亢，大妖辈出 |
| **2025 年 (全年)** | 179 天 | **31.28%** (56/179) | 23.10% | **+8.18 pp** | 震荡博弈，题材轮动加速，高度受限 |
| **2026 年 (1-8月)** | 93 天 | **22.58%** (21/93) | 15.02% | **+7.56 pp** | 存量严监管，高度被压制，基准骤降至15% |

按全市场情绪评分（`emotion_score`）三分位切分：
- **低情绪低迷期**：Top-1 五板率 28.07% vs 基准 23.61%（Alpha +4.46 pp）
- **中情绪均衡期**：Top-1 五板率 30.97% vs 基准 22.75%（Alpha +8.23 pp）
- **高情绪亢奋期**：**Top-1 五板率 36.28%** vs 基准 21.59%（**Alpha +14.69 pp**）
> **结论**：情绪越亢奋，资金对空间龙头的聚焦效应越强，模型的头部 Alpha 越显著。

## 六、真实交易执行现实与一票否决门闸

模型打出的“理论高分”必须经过实盘可执行性过滤：

### 6.1 一字买不到与爆量分歧陷阱
- 数据显示，Top-1 个股在三板时为一字板（`one_word_proxy == 1`）的比例高达 **52.4% (178 / 340)**；
- 缩量一字的三板股走出五板的概率达 39.9%，但实盘中：
  - 若第 $t+1$ 日（四板）继续巨量封单一字开盘，散户挂单**根本买不到**；
  - 若第 $t+1$ 日打开一字爆量分歧，若无强承接，往往演化为“高开低走大阴棒”。
- **执行规则**：对缩量一字票，**严禁无脑顶板排单**，必须等待盘中分歧换手（10:30前换手充分回封）作为进场信号。

### 6.2 专属标签审计与一票否决（`audit_three_board_traps.py`）
本研究与刚上线的六大三板专属标签联动生效：
1. 🔴 `【三板-历史天花板恶庄】`（如正裕工业 603089）：近1年历史最高连板为3板，且见顶必杀一字跌停。**一票否决！模型分数再高也坚决打入黑名单，严禁买入！**
2. 🔴 `【三板-尾盘偷袭诱多】`：14:00后炸板跳水、尾盘勉强回封，主力高位派发筹码。**一票否决！禁止接力！**
3. 🟡 `【三板-同位跟风陪跑】`：三板梯队>3只时的中后排个股，存量博弈必杀跟风。**强制剔除。**
4. 🟢 `【三板-换手核心真龙】`：早盘主动封板、换手 15%+、无恶庄前科、板块身位第一。**准予作为 3进4 首要接力对象。**

### 6.3 竞价生死熔断（09:25）
所有通过三板模型筛选的候选股，次日 09:25 必须满足竞价准入：
- **只要开出绿盘（平开或低开）**：买入条件单立即**永久注销撤单**！盘中冲高一律视为诱多出货，严禁低吸，彻底规避像正裕工业般的次日跌停割喉风险。

   - 在有真龙诞生的交易日，模型 Top-1 捕获真龙的概率达到 **56.0%**。
2. **严守生产保护**：
   - 本次研究全套代码与模型保存在 `research/model_upgrade_validation/dragon_3to5_breakthrough_20261027T064500Z/`，未改动生产 BASE 模型。
3. **推荐使用姿势**：
   - 复盘时以 BASE 模型作为连板晋级主排序；
