# 第五轮独立攻坚研究报告：攻克“大盘退潮期一票禁买闸门（Regime Gate）”

**研究编号**：`dragon_regime_gate_20261027T085500Z`  
**攻坚目标**：攻克【方向二：大盘退潮期一票禁买闸门】，根治短线接力“选对票却死于大盘退潮覆灭”的系统性痛点，量化消灭 63% 的零龙退潮假阳性亏损。  
**执行原则**：完全独立推进；绝对不修改/污染生产 BASE 模型；严格时间外 4 折步进（Walk-Forward）交叉验证；特征严格限定在 $T$ 日收盘已知信息。

## 一、方向二攻坚背景与痛点数据归因

### 1.1 震撼实证：72%~80% 的模型“选错”本质是“大盘全军覆没”

在第四轮回测产生的 449 个交易日中，对模型 Top-1 选错的交易日进行了穷尽式错误归因：
- **空间高标失败天数**：325 天（占 72.4%）。
- **全池零龙通杀天数（Zero-Space Days）**：在这 325 个失败日中，**整整有 260 天（占 80.0%！）是全市场当天所有三板个股无一幸免、全部覆灭！**
- **连续五板失败天数**：320 天（占 71.3%）。
  - 其中 **233 天（占 72.8%）是全市场三板股全部未能走到五板！**
- **双零冰点退潮日**：全市场三板既无空间高标也无五板突破的天数高达 **193 天（占全市场交易日的 43.0%）**！

> **核心结论**：任何选股模型在面对这 193~260 个“零龙通杀退潮日”时，命中率必然为 0%！这种亏损不是个股挑选（Stock Picking）逻辑有问题，而是**宏观/短线大盘处于退潮冰点的系统性风险**。若不在大盘环境层设卡，无论怎么优化个股特征，都会遭受 100% 的接力亏损！

## 二、双臂方案设计与量化机制

我们在 599 个历史交易日（150 个成熟训练日 + 449 个测试日）中，对比了两套严格的禁买闸门方案：

### 2.1 Arm A：规则型短线情绪硬闸门（Heuristic Rule Gate）
依据资深短线选手盘面经验制定的 4 大硬约束：
1. **高位空间垄断与断层风险**：全市场最高板 `market_max_board >= 7`（老龙头垄断资金，三板个股处于腰部断层尴尬身位）且个股评分 `< 0.32`；
2. **炸板与亏钱效应恐慌**：全市场炸板率 `failed_rate >= 38%` 或昨日涨停溢价 `yesterday_premium < -1.5%`，且个股评分 `< 0.32`；
3. **情绪逆转加速恶化**：情绪恶化转移概率 `emotion_adverse_next_probability >= 60%`，且个股评分 `< 0.32`；
4. **孤狼高位诱多**：个股为孤狼（`is_isolated_lone_wolf == 1`），全市场最高板 $\ge 6$，且个股评分 $< 0.35$。
- **执行规则**：命中任一规则即触发 `GATE_CLOSED`（全市场三板一票禁买，次日任何冲高翻红视为诱多出货，严禁低吸追高）。

### 2.2 Arm B：机器学习退潮概率闸门（ML Walk-Forward Probability Gate）
- 采用 `HistGradientBoostingClassifier` 在每个时间折的训练集上，利用 18 个全市场宏观情绪、梯队高度差、吸金体量指标，纯外推预测次日全市场三板是否为“真龙交易日 (`is_dragon_day`)”。
- 输出日度退潮概率 `prob_dragon_day`。
- **步进回测折数（4-Fold Walk-Forward）**：
  - Fold 1：Train 150 天 $\rightarrow$ Test 75 天，**AUC = 0.6187**
  - Fold 2：Train 225 天 $\rightarrow$ Test 94 天，**AUC = 0.6548**
  - Fold 3：Train 319 天 $\rightarrow$ Test 111 天，**AUC = 0.7084**
  - Fold 4：Train 430 天 $\rightarrow$ Test 169 天，**AUC = 0.7583**
  - **全周期样本外综合 AUC 达到 0.7295**！
