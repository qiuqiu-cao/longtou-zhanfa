## 一、方案一：同花顺电脑客户端【公式管理器】导入指南（推荐）

通过同花顺公式编辑器新建【条件选股公式】，可在每日 09:25 集合竞价定型后，一键秒级扫描全市场股票，选出当日大概率涨停的非一字龙头标的。

### 步骤 1：打开公式管理器
- 打开同花顺电脑版客户端，登录交易或行情账号；
- 键盘直接按下快捷键：**`Ctrl + F`**；
- （或点击客户端顶部菜单栏：**【工具】 -> 【公式管理】 -> 【公式管理器】**）。

### 步骤 2：新建条件选股公式
1. 在弹出的“公式管理器”左侧树状目录中，点击展开 **【条件选股】**；
2. 选中其中的任意子分类（如【其他选股】或点击【条件选股】根目录）；
3. 点击右侧的 **【新建】** 按钮。

### 步骤 3：填写公式基本信息
在“条件选股公式编辑器”窗口中，填写以下信息：
- **公式名称**：`龙头竞价非一字`（或自定义名称如 `竞价大概率涨停`）
- **公式描述**：`09:25集合竞价大概率涨停选股(非一字黄金高开+爆量抢筹)`
- **公式类型**：保持默认（条件选股）

### 步骤 4：粘贴公式源码
将以下代码完整复制，并粘贴到下方的公式代码编辑框中：

```pascal
{=============================================================}
{ 公式名称: 龙头竞价非一字选股                                  }
{ 适用软件: 同花顺 PC 电脑版公式管理器                          }
{ 触发时点: 09:25:01 集合竞价定型后执行选股                     }
{=============================================================}

{ 1. 基础过滤：排除ST、*ST、退市整理 }
NOT_ST := IF(NAMELIKE('ST') OR NAMELIKE('*ST') OR NAMELIKE('退'), 0, 1);

{ 2. 涨停幅度动态计算（主板10%，创业板/科创板20%） }
IS_20 := IF(CODELIKE('300') OR CODELIKE('301') OR CODELIKE('688'), 1, 0);
ZT_MULT := IF(IS_20, 1.20, 1.10);
ZT_PRICE := ROUND(REF(CLOSE, 1) * ZT_MULT * 100) / 100;

{ 3. 昨日涨停确认（昨日收盘达到涨停价且收盘等于最高价） }
ZT_PREV_MULT := IF(IS_20, 1.195, 1.095);
ZT_PREV_PRICE := ROUND(REF(CLOSE, 2) * ZT_PREV_MULT * 100) / 100;
YESTERDAY_ZT := (REF(CLOSE, 1) >= ZT_PREV_PRICE - 0.01) AND (REF(CLOSE, 1) = REF(HIGH, 1));

{ 4. 核心条件一：非一字开盘（开盘价低于涨停价，散户可以挂单买入） }
NOT_ONE_WORD := OPEN < (ZT_PRICE - 0.01);

{ 5. 核心条件二：09:25 黄金高开区间（+2.0% 至 +7.0%） }
GAP_PCT := (OPEN - REF(CLOSE, 1)) / REF(CLOSE, 1) * 100;
GOLDEN_GAP := (GAP_PCT >= 2.0) AND (GAP_PCT <= 7.0);

{ 6. 核心条件三：竞价爆量抢筹（竞价金额占昨日成交额 >= 5.0% 或量比 >= 15） }
{ DYNAINFO(15) 为同花顺集合竞价成交额（元），DYNAINFO(17) 为开盘量比 }
AUCTION_RATIO := (DYNAINFO(15) / REF(AMOUNT, 1)) * 100;
EXPLOSIVE_VOL := (AUCTION_RATIO >= 5.0) OR (DYNAINFO(17) >= 15.0);

{ 7. 核心条件四：跳空突破（竞价开盘价大于等于昨日最高价，实现全员浮盈无套牢盘） }
BREAK_HIGH := OPEN >= REF(HIGH, 1);

{ 8. 核心条件五：容量与换手健康度（昨日成交额 >= 3亿元，昨日换手率 8% ~ 32%） }
PREV_TURNOVER := (REF(VOL, 1) / CAPITAL) * 100;
HEALTHY_CAPACITY := (REF(AMOUNT, 1) >= 300000000) AND (PREV_TURNOVER >= 8.0) AND (PREV_TURNOVER <= 32.0);

{ 9. 最终选股输出 }
XG: NOT_ST AND YESTERDAY_ZT AND NOT_ONE_WORD AND GOLDEN_GAP AND EXPLOSIVE_VOL AND BREAK_HIGH AND HEALTHY_CAPACITY;
```

### 步骤 5：编译测试与保存
1. 点击编辑器右上角的 **【测试公式】** 按钮；
2. 下方提示栏出现：**`编译测试通过！`**；
3. 点击 **【确定】** 按钮保存公式并退出公式管理器。

### 步骤 6：每日 09:25 如何执行选股？
1. 每日上午 **09:25:01** 集合竞价定型后；
2. 键盘按下快捷键：**`Ctrl + T`**（条件选股）；
3. 在左侧列表中选中 **【龙头竞价非一字选股】**；
4. 选股范围选择：**【沪深主板】**（或【全部A股】）；
5. 点击右下角 **【执行选股】**；
6. 系统会在 1~2 秒内输出符合条件的 2~5 只精选个股，直接加入自选股监控！

## 二、方案二：同花顺【问财 (Wencai)】一键搜索与策略保存指南（最便捷）

同花顺问财内置全国最强大的自然语言量化检索引擎，不仅免去公式编辑器的繁琐代码，还支持移动端与 PC 端多端云同步！

### 核心战法问句清单（直接复制使用）：

#### 战法 1：【连板接力·非一字爆量真龙】（主力推荐：2进3、3进4、高位成妖）


### PC 端问财操作步骤：
1. 打开同花顺电脑版，按快捷键 **`Ctrl + Q`** 或点击顶部导航栏的 **【问财】** 标签；
2. 将上述任意一句完整问句粘贴进搜索输入框；

## 三、方案三：同花顺【条件预警系统】自动弹窗与声音报警设置

如果您想在 09:25 盘前不需要手动按快捷键，让同花顺自动发出声音警报并弹出候选股票窗口，可以配置【条件预警】：

1. 快捷键：按下 **`Ctrl + Alt + W`**（或点击顶部菜单栏：**【系统】 -> 【预警系统】 -> 【条件预警设置】**）；
2. 点击 **【预警品种设置】** -> 点击 **【添加品种】** -> 选择 **【沪深A股】** 或【自选股】；
3. 点击 **【预警公式设置】** -> 点击 **【添加公式】**；
4. 在公式列表中选择之前创建的 **【龙头竞价非一字选股】**，预警周期选择 **【日线】**，勾选启用；
5. 点击 **【其他设置】**：
   - 勾选：`弹出预警列表`；
   - 勾选：`发出声音警报`；
   - 勾选：`自动加入预警板块`；
6. 点击确定退出设置，并在交易日 09:20 开启预警开关。09:25:01 一到，符合条件的真龙个股将立即伴随警报声自动弹出！

## 五、09:25~09:35 微观盘口排雷与打板实战执行闭环（防吃大面）

> [!CAUTION]
> **切记**：选出股票 **绝对不等于盲目无脑挂单买入**！实战中恶庄常在竞价利用虚假高开诱多（如正裕工业、茂业商业型）。必须严格执行以下四步排雷闭环：

### 1. 09:20~09:25 不可撤单阶段排雷
- **买盘实度检查**：查看买一挂单金额。若买一挂单不足 10 万元（甚至只有几十手，买盘严重空心），属于典型的“买盘虚空假高开”，坚决一票否决！
- **衰减率排雷**：观察 09:20 与 09:24:50 的匹配量变化。若 09:24:50 匹配量比 09:20 缩水超过 30%，说明主力在最后几秒撤单留散户挡枪，坚决不碰！

### 2. 09:25 竞价定型生死熔断
- 🔴 **绿盘低开（<=0.0%）或平开陷阱（0%~+2%）**：大数据证实绿盘低开接力失败率高达 **80.9%**，一律触发【竞价生死熔断】，买单立即注销撤单！盘中任何反抽一律视为出货，严禁低吸！
- 🟢 **黄金高开（+2%~+7%）且竞价放量**：主力真金白银主动抢筹，保留买入条件单。
- 🟣 **顶格一字（>=+9.5%）**：作为板块情绪风向标观察，严禁散户盲顶缩量一字（一旦盘中炸板就是 15%~20% 大面）。

### 3. 09:30 开盘后打板买入执行
- **条件单一（放量回封打板）**：09:30 开盘后，个股快速上冲触板，若开盘分时成交量持续放大且买一封单迅速堆叠，果断在涨停板价位挂单排单买入！
- **条件单二（分时均线低吸）**：若开盘冲高后小幅分歧回踩，分时线在黄色成交均线（VWAP）上方止跌企稳、再次放量拐头向上时加仓买入！

严格遵循本手册，即可彻底摆脱机械死板的看盘困境，在每天开盘前 09:25 第一时间锁定全市场最强真龙！
