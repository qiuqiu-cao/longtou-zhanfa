# 接口与复用说明

先按原relay_review_workbench完成股吧、完整历史/主线/叙事和父锚输入及作者审阅。研究上下文用：

```powershell
python historical_price_relation_workbench.py context --facts <原完整facts.json> --bundle <已更新到信号日的完整engine.joblib> --output <新遮蔽分数context.json>
python historical_price_relation_workbench.py score --facts <原完整facts.json> --context <新context.json> --review <原已完成审阅.json> --model <2026-10_model.joblib> --output <新研究分.json>
```

新日期不能复用旧日期池；engine须绑定当日完整收盘/炸板来源及此前日线。缺日线不跳到最近成交日，未知配对不删除。本接口仅追加研究视图，不写原facts或正式登记。当前已运行且批量/单日相同。该模型已失败，不是生产推荐。
