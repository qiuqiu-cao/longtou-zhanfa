## 研究模型使用

训练入口为项目根目录first_second_stage_model.py；保存权重为本目录first_second_stage_bundle.joblib。first_second_stage_workbench.py prepare从指定合格日线、官方日历和证券状态区间生成无分数事实/特征，按原流程独立判断留档之后，recheck才显示研究分数。第二日传入原首板输出作为--prior-selection，会在二板重新评分中标识昨日首选，并绑定哈希，不写回原首板预测。

```powershell
python .\first_second_stage_workbench.py prepare --bars <已核验历史行情.csv> --recovered <恢复股票行情.csv> --calendar <官方交易日历.json> --security-intervals <证券区间.csv> --signal-date YYYY-MM-DD --output <新的遮分特征.csv>
python .\first_second_stage_workbench.py recheck --bundle research\first_second_stage_20261020_run1\first_second_stage_bundle.joblib --features <新的遮分特征.csv> --output <新的研究评分.csv> --prior-selection <前一日研究评分.csv>
```

首次没有前日首选文件时省略--prior-selection。新信号须晚于模型2026年8月31日知识截止，输入覆盖所声明完整池；当前没有生成2026年10月实盘预测。概率输出仅具有本历史归档上的时间样本外校准资格，不能冒充真实盘口、成交或龙头概率。
