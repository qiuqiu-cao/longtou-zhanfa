# 全候选同花顺题材：固定实验设计讨论稿

结论：支持继续按原完整池采集、构建和检验；**当前并未共同冻结、未审阅新源码/数据，也未拟合**。建议两臂分别回答“同花顺单源相对S1”与“同花顺在既有KPL题材臂之外是否增量”。保留旧S1、旧A及旧B原封不动作为已运行的参照，不能将新实验包装成前瞻验证或把旧A的历史胜出视为预先盲选的最优底座。

## 1. 样本范围与可用性

- 对既存7254条、286个信号日涉及的全部1660只不同代码建采集清单；需保留代码、申请与实际响应、缺页/403、事件日期不在页面可见范围、链接验证失败、无题材、源版本与实际取得时间。最多展示最近若干次事件的页面，对较早日期的缺席应记 `NOT_IN_VISIBLE_HISTORY_OR_UNKNOWN`，不能称该日无涨停或无主题。覆盖以**候选×日期**、日期、股票分别汇总；全部代码都尝试不等于全部候选日期都取得。
- 1660只来自整个历史评估池的事后代码集合，包括后来才进入池的股票，具有跨期选择及可能幸存者偏差；也缺未进过首板合格池的高位、低位、炸板和大市值股票。新增THS组只能称“固定全期候选代码集合中、该日有合格来源和价格的可观察组”，并非全市场主题成员。不要将获得所有1660个网页与每日期题材覆盖完整混为一谈；把页面长度截断和非随机缺页分开统计。
- 同花顺详情以原股代码及事件日期逐条验证，逐日原文、网址、链接目标、接收时刻及哈希可追溯；仅事件日匹配不证明当日发布或当时版本。论坛用于提出和反驳叙事、补充实际成员，正文与评论分别登记，不从晚到帖子回填历史日、也不利用未来赢家筛选成员。主题文本归一化、拆分、空值及跨来源映射规则先写死；不以名称同字自动归组或加分。
- 为减少覆盖选择偏差，先汇报无标签数据的每月/每日覆盖，包括全部候选、主题可取、详情验证、已绑定、页面截断与失败，旁列价格状态已知范围及同题材可观察成员数量。若某日无有效同伴，相关字段未知而非0；若锚可能未纳入代码集合，不能断言“全市场无锚”。不以有覆盖的日子替代完整主验收日期。

## 2. 建议固定的最多两臂

**T：S1 + THS单源增量。** 以原S1的 `logit(s1_score)` 为固定偏置，对THS已观察子集的相对状态做固定L2成对残差。各字段名称须明确 `ths_observed_subset`，只比较同源、同日期可绑定的成员；不在THS与KPL间简单拼接、把同义词视为同源成员或计作独立票数。旧的相对收益/续板及前锚算子可沿用，但输入源和成员范围必须明确不同于旧失败臂；THS不存在可信首封时间时该字段全未知，不从收盘结果补时间。

**K+T：以旧A逐月已保存的历史滚动预测作为固定底座，再拟合THS增量残差。** 具体底座应逐行重构为 `logit(s1_score) + old_A_saved_residual`：旧A的冷启动/回退月份 `residual=0`。**不能直接把旧A保存的 `research_score` 全列当同一量纲偏置**，因为其拟合月为logit尺度，而回退月直接保存S1原分数。对各历史训练行使用它在自身信号日由原旧A滚动模型事先计算的已保存残差，不使用当前月的旧A模型回算历史训练行；将全部原A逐月模型、残差、来源和时钟绑定。训练和推断中保持该偏置系数1，不重训或改旧A。此臂用于观察是否能在一个已知参照上增量，因选择旧A发生在已看其结果之后，只是探索性对照，不独立认证增益。

T没有THS可用变量或失败时逐月/逐日按既定规则回退S1；K+T相应回退旧A，旧A自身回退月仍为S1。单股缺失时THS残差为零，不保证其相对排名不变：别的股票调整仍可把它挤出前三。整日THS信息全部缺失必须与各自底座的**全池排序逐股一致**。K+T的完整每日前三既要与S1比，也要与旧A比；T与S1比。严禁凭结果改变底座或从两个新臂中选较高者再称预先固定。

七字段是否实际进入模型须由数据资格决定，而非为凑数填零：优先保持旧算子定义、把不支持的列全空并由训练窗处理，写清共同主题、时间和高位锚可观察范围。不能混用KPL已有高位与THS题材声称其为同源完整组；如需跨源连接，应事先说明匹配规则及冲突/未知处理，不能在看到回测后修正。供讨论的最低限定：组内只有候选本人或没有一个已观察同伴时对应比较未知；前组任一所需已观察成员当日价格未知时该组反馈未知，不剔除失败股、不按可见成功者求均值。锚组仅可说“可观察子集内最高锚”，不能将子集无锚作为全市场不存在。

## 3. 时间、训练与回退的固定边界

1. 沿用既存月度日历、最多252成熟信号日、至少60日、日内全部正负对及按日等权、固定L2=1、原求解器参数和零初值；任何变化须在拟合前写明原因并共同冻结，不按收益调参。每月训练窗只用各行 `label_end≤前一官方交易日截止` 的已成熟标签，标准化用该窗全部候选的有限特征；未来标签不能进入组构建、采集范围选择或特征表。
2. S日组只允许用S日及以前的事件日期构造，S−1固定成员和锚只用S−1及以前的事件及价格状态；S日价格反馈仅取S收盘及以前事实，S日未封板或缺价的前组成员保留。独立测试删除未来事件和后续交易日后，S日特征完全不变；禁止把次日竞价、盘中或未来结果用于S日排序。
3. 后补THS或KPL来源不因事件日期在S日以前而成为严格时点证据；接收时间及版本未知分别保存。严格新信息通道不能使用由后补信息训练的系数；若无具备资格的实时版本和对应权重，严格通道回退S1或标示原S1历史回放资格，不能拿探索臂冒充实时可用。
4. 至少验证：截断页面不误识别为否定；详情链接股/日不符排除；单股无同伴为未知；无价格/停牌不变失败；并列锚、重复主题、代码更名和缺失组；A/B底座单位一致；所有THS缺失时分别与S1/旧A逐股排序完全一致；输入哈希变化停止运行。未来数据截断不变只证明计算顺序，不能弥补后补来源版本风险。

## 4. 验收与事前冻结资料

保留原筛选、286完整日、每日三名、858名额及逐次未知。原S1=261/852、旧A=267/852、旧B=264/852均引用原保存名单，不重跑失败臂；新结果重新接独立标签计算各自已知、未知及完整槽确认占比和40%差距。每次换入/换出列一进二成功/失败/未知、四板路径损益和首板日非一字分组；列具体当时可见的信息、模型贡献、替换竞争者及反证，但账务配对不自动证明因果。比较新臂与S1及K+T与旧A的完整日期、分月和覆盖分层；25日配对块区间为描述性、不具事后选择校正。交易盈利、可买性和晋级是不同问题。

采集完成先保存源覆盖、无标签特征、源码测试、精确定义与所有输入哈希，核对原基准、保护文件和冷启动/回退。再由两个实际会话分别审阅同一版本并明确确认，然后才按用户授权做一次固定比较；此前不能声称已冻结。已经被反复观察的286日只能作历史探索，后续真正增量仍需未用于设计的严格时点前向验证。

## 5. 对最新修订的讨论反馈

收到当前执行会话的修订：T以S1为底座，K+T以旧A对应月已保存的逐行滚动残差重建底座；无当前同伴的广度与时序、无前组或无前组可观察合格锚的相关字段均为未知。THS无可信首封则时序全空；前组保留当日失败股，所需价格缺失时反馈未知。字段冠以 `observed_subset`，严格通道回退S1。这个方向与上述讨论一致，可继续实现并在无标签条件下进行合成测试，**不代表对实际源码、数据或协议的冻结确认**。

补充核查要点：

- 前组收益/续板比较须同时写明题材原组与全样本背景的实际成员数、代码及排除候选自身的方法；两侧均须有可观察成员且所需价格齐备。零收益差或零续板率差可表示被观察组的实际计算值，但不能说明全市场没有变化。
- 复核旧A底座时逐行使用对应月份已保存模型及其对应月预测，验证 `logit(S1)+residual` 与原排序一致；冷启动残差为零。K+T训练用每条历史行各自的原月预测，不能用预测月模型回算历史行。整日无THS信息时，对两臂分别检查与S1、旧A的**完整全池顺序**一致，不只是前三集合一致。
- 目前“500次新增请求约9%可读”仅是进行中的粗略采集状态，并非最终覆盖率，更不代表7254条候选日的覆盖。先完成并固定所有1660个代码的请求记录，再按日期及候选统计；每只页面可展示事件次数有限，不能因股票页面成功就把它在每个历史日视为已覆盖。不得因为当前成功率调整样本或依据效果挑选可读页面。
- 固定阶段应保存原返回、逐事件详情核对、不可见历史/缺页原因、输入哈希、分月成熟标签和模型保护；只有该版本形成、双方实际复审并确认后才能拟合。若页面内容实际历史版本不明，整个新来源仍是后补探索，严格通道不能继承探索系数。
