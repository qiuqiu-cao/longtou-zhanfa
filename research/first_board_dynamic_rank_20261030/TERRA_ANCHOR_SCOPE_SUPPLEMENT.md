这是本次所存数据和价格资格口径的交集，不是对接口产品定义或全市场范围的官方证明；但足以说明该返回集合在本数据上**几乎全为首板**，无法作为高位锚全集。接口未返回的高位股票不能解释成没有高位股票或没有题材。

准备文件的 `prior_anchor_relative_return` 和 `prior_anchor_relative_survival` 各仅7条非空；`prior_anchor_height_gap` 5,564条有值，其中5,557条为0、7条非零。当前 `dynamic_features.py` 对上一日返回的主题组最高板不足3时赋0；在该接口几乎只返回首板的现实范围下，这个0仅是“**返回子集中未发现合格锚**”，不能称“市场或同题材不存在高位锚”。因此 5,557个零不能作为已核无锚真值，也不能拿高覆盖率冒充已接入补涨。字段既未进入市场拟合，也不构成模型效果。

## 2. 我支持的修正方向

从既存完整价格状态中查找 S−1 的可观察≥3板候选，再用该股票 **S−1及以前真实已出现的题材观察**构造有限历史绑定，是比从Type=4当日返回池直接寻找高板更合理的代理。例：某股D日以首板出现在接口，D后连续涨停而接口不再返回它；S−1按连续价格状态已是4板，就可把D日观察到的题材作为“较早供应商报告关系”追溯到其S−1锚候选，而不凭S日高位的名称推测题材。

但价格全集本身仍受既有证券池、停牌、除权、缺日及价格有效性约束；较早题材也可能已过时、与当下实际炒作不同，且后补源历史版本仍未认证。得到的只是“**可观察历史题材绑定的价格高位锚代理**”，不认证真实题材归属、主线身份、补涨父子或资金流向。严格时点通道仍不得使用后补来源和由其训练的系数。

## 3. 建议在写入新版固定协议前明确的语义

1. **两条时间线分开**：记录每条主题首次与最近一次出现的交易日、原始行、源路径/哈希、实际取得时刻、主题集合；价格状态另记每交易日的高度及有效性。形成S日研究特征时，旧观察的**观察日必须≤S−1**，相关锚高度只能取S−1，锚的当日收益和续板只可用S日收盘及之前的事实。当前候选S日主题不得反写其S−1或更早成员。
2. **固定有效期和更新语义**：先明确以官方交易日计算的最大追踪期限、起止是否含端点、S−1当天观察是否计入，以及一次新观察如何更新原始主题和过期主题。是否允许跨断板、缺失/停牌、除权或重新启动分别明确；不能因后来成为高板才延长有效期，不能在看到新增回测结果后调窗口。10日等窗口若被提出，须是待双方讨论的固定设计，不是已经验证的最优值。
3. **缺失不冒充撤销或无锚**：区分“无任何此前可用主题观察”“上次观察已过期”“价格路径不完整”“主题不匹配”“已观察锚未达高度”和“在**可追踪已知集合**内未发现合格锚”。最后一种仅为范围内观察，不能命名为全市场/全题材无锚；此前来源不全时，该结论不应自动赋0。材料或交易日缺口不得静默延长关系、凭后日记录补前日标签。真实上市、退市和证券池幸存者偏差也要列覆盖。
4. **固定组与市场背景分母**：明确是逐题材沿用 S−1 前一定窗口内已观察成员，还是只沿首板事件逐期追踪；两者覆盖不同，不能混叫“全市场同题材”。先固定成员再查看S日所有成员的价格，包括S日没有涨停、失败或价格缺失者；按股票去重，候选自身排除，组和市场对照的时间窗口、资格一致。输出成员表、缺失数和完整/部分状态，不能将仅有完整数据的幸存成员平均值称完整组反馈。保留新加入与原组成员、重叠题材分别记账。
5. **高位锚和并列**：先从S−1有效价格状态在已追踪成员里选最高高度，保留并列并逐一保存证据；对照组应由同等可追踪资格构造，不能拿Type=4直接代表全部市场高标。未在已存价格池内的标的要标未覆盖；断板但仍具辨识度的老核心不满足“连续高度≥3”时，仍不能被该单一规则捕获，若另加入断板锚，须明确区别并在两臂上限内预先讨论。
6. **名称叙事单列**：Type=4的概念文本不等于已验证名称叙事；阳/洋/羊匹配既不能自动加分也不能自动否认。九阳—百洋—海洋王只能在其日期及现有真实源与价格数据有资格时做案例复核，当前所引用states不保证覆盖10月案例，不能拿后补赢家来选择锚或确定期限。
7. **探索与严格资格**：新历史追踪若用后补题材，即使S−1逻辑截断完全正确，仍只能成为后补来源探索；`observed_date≤S−1` 不等于 `source_received_at≤S−1`。严格通道必须同时审查原始快照取得时间及每月训练数据来源；无合格来源或权重仍应原样回退S1，不把历史重建叫独立盲测。

## 4. 最少必要检验与产出

- 加合成时序测试：D日首板观察→D+1、D+2连续封板但接口缺席→S−1仍为高板时可按固定有效期发现；将S及以后观察删去后，S的特征必须完全一致；S日第一次出现的题材不能倒灌S−1。
- 加过期边界、同日/次日截止、并列锚、候选自身排除、多主题重叠去重、前日源缺失、缺价/停牌/非相邻日期、改名及新主题变更的对照，明确未知不会变成0或自动淘汰。原始状态缺失及不具备连续板资格时不得把它当可确认锚。
- 增加仅数据资格的统计：全部价格高位股数、其中有在固定窗口内的可追踪历史题材观察数、追踪过期/缺失/价格不合格数；原样保留分月、组大小、原始锚/成员代码、观察日期及证据。与旧只用Type=4的结果比较覆盖结构，不用它作为效果选择阈值。
- 原 `prepared/` 的7条非空和大量零值应原样保存并追加**范围纠正提示**；修复版进入新目录，不覆盖旧证据，不能用新结果追溯宣称前一版已正确实现。

目前仅支持继续按上述约束完善方案与合成验证；**仍不确认冻结，当前尚不符合训练条件**。新完整定义、源码、数据与测试形成后，需要主会话和本会话实际复审同一份内容并确认，然后再按用户授权推进固定研究比较。

## 5. 首板主题沿本轮连续板绑定：V2 设计初审

以连续涨停链替代任意交易日 TTL 是可以继续实现和核查的设计：逐股沿官方交易日验证本轮从1板起高度逐日递增且价格资格成立，仅把本轮首板日的供应商主题关联到该轮后续连续板；链断或首板主题不可用时保持未知。它消除人为期限和误借上一轮主题的问题，但只代表“本轮首板报告的主题代理”，不能证明整轮真实叙事不变，也不能覆盖断板后仍有辨识度的老核心或后来出现的新叙事。

V2 必须使以下边界可核，并在完成实现后再复审：

1. **先固定队列，再观测失败**：S−1各主题中可绑定的完整价格涨停成员构成前组；S日跟踪前组每个成员的价格与晋级状态，即使其未涨停、断板或不再属于S日涨停集合也仍保留；停牌、缺价、资格不明分别标未知。不能用S日涨停集合回筛前组，否则会丢失失败者。S日新成员单独统计。
2. **限定价格覆盖及连续性**：逐日核官方交易日、代码身份、有效涨停价格、连续高度及其来源；缺一天、停牌、上市或历史截断导致首板不可确认时标未知，禁止跳日拼接、借上一轮首板或按未来状态补全。保留全集内总数、已绑定、各未知原因及原价格池的上市/退市和幸存者限制，不称全市场完整题材。
3. **主题稳定是假设而非事实**：记录首板日期、股代码、首板主题及原始行、源文件哈希、实际取得时间、链龄；按股和主题去重，保留多主题。S−1题材锚与S日当前候选的题材相交是可检验关联，不自动认定补涨、带动或同资金；首板以后的叙事变化或共同催化须另作证据和反例。
4. **时点和锚定义**：S日收盘研究中，锚只能由S−1的合格连续≥3板与该轮首板主题构造，最高高度并列全部保留；前组S日表现只能使用S日收盘前可得事实。首板主题为后补来源时仍仅供历史重建探索；严格通道另核原时点取得和训练权重资格。不得用未来标签、下日数据或事后修订记录倒灌。
5. **首封时序与群体范围不同**：首封比较仅限有合格同日时间戳的同主题首板，缺高位时间不得排在最后或认定其后启动；群体宽度及前组反馈可纳入所有符合各自绑定条件的高位与低位。时间来源、缺失、并列、是否包含一字分别说明；先后不自动构成带动。
6. **必要合成测试**：至少覆盖连续1→2→3板且后两日接口缺席、断板次日、停牌与缺日、旧轮结束后新轮首板、更名代码映射、多题材重复、缺首板主题、并列高位、S日失败成员保留，以及删除S日之后数据后特征不变。逐项核实无未来泄漏，并展示分母流转，不以历史结果挑选绑定规则。

这一节仅审阅提议，不代表已审阅或确认 V2 代码、数据与固定协议，更不代表已冻结或完成训练。原先关于固定 TTL 的建议在本连续链代理范围内由此修订取代；对于断板后跨轮追踪，仍需另行定义，不能暗中继承本轮主题。
