# 首板连板潜力模型

已训练并保存 `hist_gradient` 研究模型，主目标为首板之后连续达到四板。三板、五板和同期首板最高连板高度代理分别评价。模型分数的概率未验证，不能解释为真实龙头概率。

最终核验报告在 `verified_delivery/首板连板潜力模型_训练回测报告.md`，逐项核验收据在 `verified_delivery/verification.json`。原报告、17次实际拟合、最初的CSV精度核验失败脚本和全部预测均原样保留；修复只涉及读取和报告，不增加拟合。

2025年7月至2026年8月共286个归档候选日，Top3选出858条，其中838条路径可核、20条未知；四板命中51条，固定低换手基准30条。五板命中22条，基准11条。四板Top3的全正例召回仅17.47%，2026年单段优势区间仍跨零。股票范围并非已认证完整历史全市场，仍存在幸存者偏差。

固定排序门通过；交易收益门未通过。Top1开盘买入／B+2退出的扣费情景组合回报为-52.71%，最大回撤约-53.42%，均不能冒充实际成交收益。不能把本次排序增益解释为可实盘盈利或已认证龙头识别能力。原生产模型、冻结登记和定时任务未改。

## 重新训练

在项目目录执行，输出目录必须全新；不要为了本批测试结果修改参数重跑：

```powershell
python .\first_board_leader_model.py train --output research\另一次事前登记的新实验目录
```

原始输入固定使用现有V16逐日期证券状态重建行情、被恢复股票行情、V279官方交易日历和V11证券状态区间。本批校验所有28,503条首板的独立历史证券区间均匹配，但不因此宣称补齐全市场母池。

## 对新日期生成研究排序

输入必须包含足够历史的已核验不复权日线及原字段，覆盖所声明股票范围；证券状态、交易日历也要扩展至目标信号日。不要拿当前分类填历史状态。将下面占位路径替换为实际合格文件：

```powershell
python .\first_board_leader_model.py rank `
  --bundle research\first_board_leader_20261020T114600Z\first_board_leader_bundle.joblib `
  --bars <更新后的逐日期状态行情.csv> `
  --recovered <更新后的恢复股票行情.csv> `
  --calendar <覆盖该日的官方日历.json> `
  --security-intervals <历史证券状态区间.csv> `
  --signal-date YYYY-MM-DD `
  --output <新的研究排序.csv>
```

`rank`仅使用信号日及以前的原始行情计算44项特征，保留归档范围内全部首板；拒绝旧训练日期、非官方交易日、空池和覆盖已有输出。输出包含研究名次和未校准分数，另外绑定输入哈希。它不发布买入指令，也不替换原工作台。按项目原流程，独立判断须先留档，再向分析者展示研究分数及冲突。

已准备好完整特征表时，也可以用 `score --bundle ... --features ... --output ...`。该入口要求44项特征、日期/代码及 `first/eligible/scope_known` 三个已核状态，CSV按 `float_precision="round_trip"` 读取。未来标签不会写入新排序输出。

## 审查与复现

`models/`含每次拟合前后收据、精确训练成员和保存权重；`evaluation_ALL_PREDICTIONS.csv`保留完整测试池，误报及漏报分别在对应CSV。`monthly_top3_reach4.csv`保留所有月份的退化情况。最后归档日期排序只是2026年8月31日的历史研究附页，不能当作当前市场推荐。

执行情景按事前固定成本计算：整手、现金和仓位限制、涨跌停开盘取消、T+1、延期退出、佣金、印花税、过户费和双边不利滑点。原CSV中的entry_price/exit_price为包含不利滑点的有效成本价，不是经确认成交报价；有效成本可能超出当日OHLC范围，只能用于保守成本情景。实际成交笔数为0，实盘净收益未知。

专项代码检查：`python -m pytest tests/test_first_board_leader_model.py -q`。本批核验覆盖全部17个模型保存加载、全部候选的未来路径标签、精确训练成员／标签成熟时间、两个历史截断下全部44项特征的因果一致性、组合现金与盈亏对账。核验没有重拟合。
