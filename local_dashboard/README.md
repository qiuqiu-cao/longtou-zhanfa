# 龙头战法：本地私用网页初版

双击 `启动网页.cmd`。电脑打开 http://127.0.0.1:8766/ 。启动器打印手机地址，手机与电脑接入同一局域网后，用完整的含 `key` 链接进入。电脑必须开机且服务运行；关闭浏览器不停止服务。双击 `停止网页.cmd` 只停止本启动器记录并核对过的网页进程。

无需购买数据、租服务器或注册域名。采集复用项目已经安装的 requests、pandas 等依赖，本次未安装新依赖。脚本优先使用本机 D:\python\python.exe；换机时需使用含这些项目依赖的Python环境。也可在此目录手动运行：

```powershell
& 'D:/python/python.exe' server.py --lan --port 8766
```

手动前台启动使用 Ctrl+C 停止。仅自己电脑查看可用 `start.ps1 -LocalOnly`。端口占用时用 `start.ps1 -Port 8767`，不要停止其他软件进程。

- 本次不加载任何模型、不训练、不改生产参数、不修改任务或交易账本。

## 手机访问

只允许本机/私有网络客户端；手机首次访问需启动器打印的随机访问密钥，之后用会话Cookie读取页面。不要转发完整链接。服务不提供仓库任意文件目录，也不提供交易、训练、系统设置或写模型接口。没有公网部署或路由器端口映射。

当前IP可能因网络变化而改变，重开启动器查看最新地址。若手机不能连接，检查是否在同一局域网、是否有访客Wi-Fi隔离，以及Windows是否允许Python在私有网络访问；本次未自动修改防火墙。手机实际设备连通性须在用户手机上确认。
